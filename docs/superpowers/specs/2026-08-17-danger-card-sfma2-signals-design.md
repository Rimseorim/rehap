# danger 카드에 SFMA2 응급신호 문구 추가 (task #17)

## 배경 / 문제

`docs/reference_manuals_summary.md` SFMA2 섹션(국소부위 특수검사, p11-32)에 병원 진료 감별의 직접 근거가 될 수 있는 위험 신호 표가 있으나 앱에 반영되지 않았다.

현재 앱의 병원 안내(`danger`) 화면 진입 조건을 전수 조사한 결과, 35개 통증부위 감별질문 거의 전부가 **"쉬는 중에도 욱신거린다"라는 단일 기준**으로만 트리거된다(예외 1건: 발목 스쿼트 깊이 케이스). 즉 휴식통이 없으면 아래처럼 실제로는 병원이 필요한 상태도 재활 루트로 배정될 수 있다:

- 회전근개가 파열됐지만 쉴 때는 안 아픈 경우
- 종아리 DVT(심부정맥혈전증)가 있지만 운동 중에만 증상이 느껴지는 경우
- 마미증후군(허리 신경근 압박) 초기 신호가 있지만 통증 자체는 심하지 않은 경우

## 검토했으나 채택하지 않은 것

**YBT 좌우비대칭 자가진단**: 애초 제안은 재평가 단계에 "아픈 쪽이 균형 잡기 더 힘든가" 같은 자가진단 질문을 추가하는 것이었다. 그러나 기존 재평가 체크리스트(`stage.checklist`)에 이미 "가동 범위가 통증 없는 쪽과 동일하거나 더 나온다" 등 좌우비교 항목이 들어가 있어 **중복으로 판단, 폐기**.

**동작검사(test 노드) 신설**: SFMA2 특수검사 중 상당수(어깨 충돌증후군 Neer/Hawkins, 고관절 SI관절, 어깨 SLAP)는 특정 유발 자세가 있어야 판별 가능한 검사다. 이는 원인 확정(cause) 이전 감별질문 흐름에서 다룰 문제이지 이번 범위(정적 문구)가 아니므로 별도 백로그로 분리.

**고관절 FAI, 무릎 인대/반월판, 발목 하이 안클스프레인**: 초안에는 포함했으나, 원문 기준이 "특정 자세(굴곡+내회전, 조임/외회전 스트레스)로 유발했을 때"라는 전제를 문구화 과정에서 누락했다. 유발 동작 없이 "통증/클릭음 있어요"로만 물으면 특이도가 없어(크로스핏 참여자 대부분이 해당) 위양성이 심각하다. 유발 자세를 넣으면 사실상 test 노드가 되어 "원인 확정 화면엔 동작검사 없음" 원칙과 충돌하므로 **폐기**.

**손목·팔꿈치·흉근**: SFMA2 참고자료에 해당 부위 특수검사 자체가 없음. 리서치 없이 임의로 만들지 않고 **스킵** (필요시 별도 리서치 백로그).

**경추(목)**: SFMA2엔 신경근병증 항목이 있으나, 앱에 "목/경추" pain site 자체가 없다. 신설하려면 원인·재활 루트까지 새로 설계해야 하는 훨씬 큰 작업이라 **스킵**.

## 채택 기준

danger 카드는 **정적 문구만**(질문·체크박스 없음) 넣기로 확정했으므로, 유발 동작 없이도 특이도가 있는 항목만 채택한다:

- 객관적으로 관찰 가능(둘레 차이 등) — 위양성 낮음
- 또는 정상 범위에서는 거의 나타나지 않는 극적인 증상 — 위양성 낮음

이 기준을 통과한 것은 3개뿐이다.

## 변경 대상

`index.html`의 `cause()` 함수(1438행 부근) — 원인 확정 시 뜨는 danger 카드. 현재 모든 원인에 공통으로 뜨는 2개 항목("관절이 눈에 띄게 부어있어요" / "만지면 열감이 느껴져요")은 그대로 유지하고, 아래 3개를 **해당 통증부위(pain site)일 때만** 추가한다.

| pain site | 추가 항목(제목) | 보조설명 | 근거 |
|---|---|---|---|
| 어깨 (`shoulder`) | 저항할 때 팔이 갑자기 뚝 떨어져요 | 팔을 바깥으로 돌린 상태를 유지하지 못하는 경우 | SFMA2 회전근개 파열 — 저항 시 급격히 팔이 떨어짐, 외회전 유지 못함 |
| 발목 (`ankle`) | 종아리 한쪽만 눈에 띄게 부었어요 | 양쪽을 비교했을 때 확실히 차이 나는 경우 | SFMA2 DVT — 종아리 둘레 좌우 차이 남12mm/여15mm 이상 |
| 허리 (`lower-back`) | 양쪽 다리에 동시에 저림이나 힘빠짐이 있어요 | 사타구니·엉덩이 안쪽 감각이 둔하거나 대소변 조절이 갑자기 안 되는 경우 포함 | 마미증후군 red flag(웹서치 확인, [ceslife.org](https://www.ceslife.org/red-flags.html) 등) — 안장부위 감각저하·양측 하지 증상·방광/장 기능 이상 |

## 필터링 로직

`getCause()`로 원인을 가져온 뒤 `S.painSiteId`(또는 원인이 속한 pain site)로 분기해 항목 3개 중 해당하는 것만 배열에 추가, 기존 2개 항목 뒤에 이어붙인다. 카드 스타일(`!` 아이콘 + 굵은 제목 + 보조설명)은 기존 마크업 그대로 재사용.

## 스코프 밖 (별도 백로그)

- 어깨 충돌증후군(Neer/Hawkins) — test 노드 후보
- 고관절 FAI, 무릎 인대/반월판, 발목 하이 안클스프레인 — 유발 자세 필요, 문구화 불가로 폐기됨(재검토 시 test 노드로만 가능)
- 손목·팔꿈치·흉근 위험신호 리서치 — 참고자료 없음, 신규 리서치 필요
