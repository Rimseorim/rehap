# 페르소나 3: 24세 남 · 크로스핏 초보(1개월차)

## 인물 배경
친구 따라 최근 등록. 밴드 풀업 연습 중 어깨 이상 느낌. 운동 용어에 아직 서투름.

## 선택 과정 (왜 이렇게 골랐는지)
- 통증부위: 어깨 — 밴드 풀업 연습 중 어깨에서 이상한 느낌을 받은 게 이 인물의 실제 경험이라 가장 자연스러운 선택.
- 동작: 풀업 — 통증을 느낀 계기가 밴드 풀업 연습이었기 때문에 그대로 선택.

## 진행 기록
1. 통증부위 선택 화면: "어깨"를 선택. → 화면 진입 시 "발목"에 파란 테두리가 이미 강조돼 있었음(실제 선택된 상태 아님, 클릭 전 호버/포커스 잔상으로 보임). 실제로 어깨를 클릭해서 넘어감. 이전 페르소나가 보고한 것과 동일한 문제 재현.
2. 동작 선택 화면: "풀업"을 선택. → 이 화면에서도 "풀업"에 파란 테두리가 이미 강조돼 있었음. 마침 이 인물의 실제 계기와 일치하는 선택지였지만, 우연이 아니었다면 다른 동작을 원했어도 헷갈렸을 것. 동일 문제 재현.
3. "어깨 통증이 느껴지나요?" (풀업·매달리기 중 찝히거나 쉬는 중에도 아픈 경우 포함): "네, 통증이 있어요" 선택. 초보 입장에서 "찝히거나"라는 표현이 정확히 뭘 뜻하는지는 감이 안 왔지만, "이상한 느낌"이 통증에 가깝다고 판단해서 선택.
4. "통증이 언제 느껴지나요?": "어느 정도 반복한 후" 선택. 처음 몇 개는 괜찮다가 반복하면서 이상함을 느꼈다는 설정이라 이 선택지가 맞다고 판단. 이 화면도 진입 시 해당 선택지에 파란 테두리가 미리 강조돼 있었음 — 우연히 원하는 답과 일치.
5. "능동 어깨 굴곡 검사" (직접 테스트, 팔을 머리 위로 들어 올려 귀 옆까지 닿는지 확인): "올리는 중 통증이 있거나 귀 옆까지 안 올라가요" 선택. 초보라 "굴곡"이라는 용어가 낯설었지만 그림 설명과 단계별 지시(1·2·3)가 있어서 뭘 해야 하는지는 이해할 수 있었음. 다만 "능동"이라는 단어의 뜻(수동 검사와 구분되는 개념)은 몰랐어도 검사 자체를 수행하는 데는 문제 없었음.
6. 원인 확정 화면: "가동성 부족 — 광배근·흉추 경직 (어깨 굴곡 공간 부족)"으로 판정. "광배근", "흉추"라는 용어는 초보 입장에서 생소했지만, 바로 아래 설명("팔을 머리 위로 들 때 광배근이나 흉추가 굳어 있으면 어깨가 충분히 올라가지 않습니다...")이 쉬운 말로 풀어줘서 이해에 큰 어려움은 없었음. → 이 화면에서 "기록 저장에 실패했습니다" 토스트가 떴음. 이전 페르소나가 보고한 것과 동일한 문제 재현.
7. 위험 신호 체크리스트(관절 부어있음/열감/팔이 툭 떨어짐) 확인: 해당 사항 없어서 "재활 루트 보기" 클릭. 빨간 박스로 강조돼 있어서 초보 입장에서도 "이건 병원 갈 상황"이라는 걸 명확히 알 수 있었음.
8. 재활 루트 화면(기초재활 1/4 단계) 진입: "누워서 오버헤드 광배근 스트레칭" 운동 카드 확인. 방법 1~4단계가 구체적이고 사진/영상 버튼도 있어서 따라 하기 쉬워 보임. "왜 이 운동인가" 토글을 눌러보니 "풀업 매달리기 자세(팔이 위로 올라간 방향)와 동일한 방향으로 광배근을 이완합니다..."라는 설명이 나와서, 내가 왜 이 운동을 해야 하는지 납득됨. 다만 "신전"이라는 단어는 초보 입장에서 뜻을 모를 수 있음(문맥상 "늘리는 것" 정도로 유추는 가능).

## 발견된 문제
- [심각도: 사용성] 통증부위/동작 선택 화면 진입 시 실제 선택하지 않은 항목(발목, 풀업, "어느 정도 반복한 후")에 파란 테두리가 이미 강조돼 있음. 클릭해서 선택한 것으로 착각하기 쉬움 — 위치: 통증부위 선택 화면, 동작 선택 화면, "통증이 언제 느껴지나요?" 화면. 이전 페르소나 보고와 동일하게 재현됨.
- [심각도: 데이터] 원인 확정 화면에서 "기록 저장에 실패했습니다" 토스트 발생 — 위치: 원인 확정("원인을 찾았습니다") 화면. 이전 페르소나 보고와 동일하게 재현됨.

## 최종 결과
- 도달한 화면/판정: danger 화면 없이 정상 진행 — "풀업 어깨 · 가동성 부족 (광배근·흉추 경직)" 원인 확정 후 재활 루트(기초재활 1/4 단계, 오버헤드 광배근 스트레칭 등) 진입.
- 이 인물 입장에서 이 결과가 납득되는지: 네. "왜 이 운동인가" 설명이 풀업 동작과 연결지어 이유를 알려줘서, 전문용어(광배근·흉추)를 정확히 몰라도 "내 풀업 자세랑 관련된 스트레칭이구나"라고 이해하고 납득할 수 있었음. 다만 "능동/신전" 같은 해부학·운동 전문용어는 뜻풀이가 따로 없어서 초보 입장에서 완전히 이해했다기보다는 문맥으로 대충 넘어간 느낌.
