# 페르소나 1: 32세 남 · 스쿼트

## 프로필
- IT숙련도: 숙련 / 증상설명정확도: 정확 / 증상민감도: 둔감 / 병원권유수용도: 수용적 / 크로스핏경력: 숙련
- 시나리오: 무릎 앞쪽 통증, 베이스라인(위험신호 없음) 케이스

## 진행 기록
1. 로그인 화면: "데모로 시작" 링크 클릭 → 기록(김서림님) 홈으로 정상 진입.
2. 홈 화면 하단 탭 "재활" 클릭 → "재활 진행 중: 스쿼트·무릎, 기초 재활 단계" 카드가 이미 표시됨(데모 계정에 과거 진행 데이터가 기본 저장되어 있음). "지금 시작하기" 클릭 → 새 감별 흐름 시작.
3. "통증 부위" 질문(진행률 10%) → "무릎" 선택 → 정상 진행.
4. "동작 선택" 질문(진행률 30%) → "스쿼트" 선택 → 정상 진행.
   - 주: 시나리오에는 "동작 → 통증부위" 순서로 되어 있으나 실제 앱 흐름은 "통증부위 → 동작" 순서. 결과에는 영향 없음.
5. "챕터1·감별 질문"(진행률 30%→43%): "통증이 언제 느껴지나요?" → 둔감 성격에 맞춰 중간 강도 답변 "어느 정도 반복한 후" 선택 (덜 심각한 쪽) → 정상 진행, danger 화면 없음.
6. "챕터1·감별 질문"(진행률 43%): "스쿼트 깊이를 얕게 하면 통증이 줄어드나요?" → "네, 얕게 앉으면 괜찮아요" 선택 → 정상 진행.
7. "챕터2·직접 테스트"(진행률 56%): 족관절 배측굴곡 가동성 테스트(그림 설명 없이 텍스트 지시 + 영상 링크 제공) → "뒤꿈치가 바닥에 붙은 채 무릎이 벽에 닿아요"(정상 가동성) 선택 → 정상 진행.
8. "원인 확정" 화면(진행률 82%): 위험 신호 카드(관절 부종/열감) 표시되었으나 경고 트리거 없이 그대로 결과 확정 — 병원 안내로 전환되지 않음. 정상(의도된 베이스라인 케이스와 일치).
   - 배정된 원인: "대둔근·내전근 활성 저하"(설명 포함, 원칙 #2 준수).
   - 화면 하단에 "기록 저장에 실패했습니다" 토스트 출현.
9. "재활 루트 보기" 클릭 → "재활 루트" 화면(기초재활 1/4 단계) 정상 도달. 운동 4종(내전근 스트레칭·피리포르미스 스트레칭·밴드 사이드스텝·싱글레그 글루트브릿지) 각각 방법/영상 링크/"왜 이 운동인가" 접이식 설명 포함. 레이아웃 깨짐 없음.
   - "기록 저장에 실패했습니다" 토스트가 이 화면에서도 재출현.

## 발견된 문제
- [심각도: 데이터] "무릎 앞쪽(anterior)" 통증을 구체적으로 특정하는 질문(예: 통증 위치가 슬개골 앞쪽/옆쪽/뒤쪽 중 어디인지)이 감별 흐름에 없음. 질문 흐름은 통증 타이밍(43%)과 스쿼트 깊이(56% 전) 두 가지만 거치고 바로 원인이 "대둔근·내전근 활성 저하"(무릎 내반·외반 정렬 문제, valgus collapse)로 확정됨 — 이는 "무릎이 안으로 무너지는" 것과 관련된 원인이지, 앞쪽(슬개대퇴) 통증과 직접 연결되는 설명은 아님. CLAUDE.md 원칙 "원인 먼저, 운동 나중"은 지켜졌으나, 무릎 앞쪽 통증 시나리오와 최종 진단명 사이의 인과 설명이 사용자 입장에서 약하게 느껴질 수 있음 — memory의 "감별 분기 얕음 패턴" 이슈와 동일 계열로 보임.
- [심각도: 데이터/사용성] "원인 확정" 및 "재활 루트" 화면에서 "기록 저장에 실패했습니다" 토스트가 반복 출현. 로컬 정적 서버(file:// 대신 http://localhost로 서빙, 브라우저 자동화 제약 때문에 부득이하게 사용)에서 재현되어 백엔드(Railway) 미연결로 인한 것일 가능성이 높음 — 실제 배포 환경(GitHub Pages + Railway)에서도 재현되는지는 별도 확인 필요. 콘솔 에러 로그는 캡처하지 못함(추적 시작이 늦어 페이지 로드 초반 로그 소실).
- [심각도: 사용성] 데모 계정 진입 시 "재활" 탭에 이미 "스쿼트·무릎, 기초 재활 단계 1/4" 진행 카드가 존재. "지금 시작하기"가 이 기존 진행 상태와 별개의 새 흐름인지, 아니면 이어하기와 결과가 같은 흐름인지 화면상 구분이 명확하지 않음(동일 사용자가 새로 시작할 때 기존 기록이 덮어써지는지 불명확).

## 최종 결과
- 배정된 cause/루트: "대둔근·내전근 활성 저하" → 기초재활(1/4) → 회복테스트 → 재평가 → 운동복귀 4단계 루트, 준비운동 4종(내전근 스트레칭, 피리포르미스 스트레칭, 밴드 사이드스텝, 싱글레그 글루트브릿지) 배정.
- 시나리오 의도와 일치 여부: 부분 일치. Danger 화면이 뜨지 않고 정상적으로 재활 루트까지 완주한 점(핵심 성공 기준)은 시나리오와 일치. 다만 "무릎 앞쪽 통증"이라는 전제와 최종 배정된 "대둔근·내전근 활성 저하"(무릎 내반 정렬 문제) 사이의 논리적 연결이 화면상 명시적으로 설명되지 않아 완전히 일치한다고 보기 어려움 — 앱이 애초에 "앞쪽/옆쪽/뒤쪽" 같은 통증 위치 세분화 질문을 하지 않기 때문으로 보임.
