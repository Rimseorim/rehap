# 페르소나 1: 28세 여 · 크로스핏 초보(3개월차)

## 인물 배경
헬스는 오래 했지만 크로스핏은 처음. 스쿼트 배우면서 몸 어딘가 불편함을 느껴 앱을 켬.

## 선택 과정 (왜 이렇게 골랐는지)
- 통증부위: 무릎 — 헬스 경력은 있지만 크로스핏 스쿼트(하이바, 풀 스쿼트, 고반복)는 처음이라 가장 먼저 부담이 가는 부위로 무릎을 떠올림.
- 동작: 스쿼트 — "요즘 스쿼트 배우면서" 느낀 불편함이므로 자연스럽게 선택.

## 진행 기록
1. 통증 부위 선택 (10%): "어디가 아픈가요?" 화면에서 무릎 선택. 선택지 8개가 명확하게 나열되어 헷갈림 없음.
2. 동작 선택 (30%): 스쿼트/런지/데드리프트 중 스쿼트 선택. 무릎 배지가 상단에 남아있어 이전 선택이 잘 보임.
3. 감별 질문 - 통증 시점 (30→43%): "운동 시작하자마자 / 어느 정도 반복한 후 / 쉬는 중에도 욱신거린다" 중 "어느 정도 반복한 후"를 선택. 3개월차 초보로 스쿼트 자세를 아직 다지는 중이라 반복하면서 피로가 쌓이며 느껴지는 통증이 가장 자연스럽다고 판단.
4. 감별 질문 - 깊이 테스트 (43→56%): "스쿼트 깊이를 얕게 하면 통증이 줄어드나요?"에서 "네, 얕게 앉으면 괜찮아요" 선택. 초보라 풀 스쿼트 가동범위 자체가 아직 부족할 것 같아서 깊이와 연관된 답이 자연스럽다고 판단.
5. 직접 테스트 - 족관절 배측굴곡 가동성 (56→82%): 벽 앞에서 무릎을 벽에 붙이는 테스트 안내. 앞선 답변(깊게 앉으면 아픔)과 일관되게 "뒤꿈치가 들리거나 무릎이 벽에 닿지 않아요"(가동성 제한)를 선택. 테스트 방법 설명이 그림 없이 텍스트+영상 링크로만 제공되는데, 순서(1,2단계)와 비교 방법(반대쪽 발 2cm 차이 기준)까지 구체적이라 이해하기 쉬웠음.
6. 원인 확정 (82%): "족관절 배측굴곡 가동성 제한"으로 진단. "발목이 잘 안 굽혀지면 스쿼트할 때 뒤꿈치가 들립니다. 뒤꿈치가 뜨면 무릎 앞쪽에 부담이 쏠려 통증이 생깁니다. 무릎보다 발목을 먼저 풀어야 합니다"라는 설명이 붙어있어 왜 무릎이 아닌 발목이 원인인지 납득이 감. 위험 신호 체크(부종/열감) 문항도 함께 제시됐는데 해당 없어 자연스럽게 "재활 루트 보기" 진행.
   - **문제 발견**: 이 화면에서 "기록 저장에 실패했습니다"라는 토스트 메시지가 하단에 떴음 (스크린샷 확인). 사용자 입장에서는 이유를 알 수 없는 에러라 불안했을 것.
7. 재활 루트 - 기초재활 1단계 (82%): "월 앵클 모빌리티" 운동 카드 제공. 방법(4단계, 15회×3세트), 팁, "왜 이 운동인가" 접기/펼치기가 있어 클릭해보니 "족관절 전방 공간을 직접 열어 배측굴곡 가동범위를 회복합니다"라는 짧고 명확한 이유가 나옴. 이유를 늘 붙인다는 핵심 원칙이 잘 지켜짐.

## 발견된 문제
- [심각도: 데이터] 원인 확정(재활 루트 진입 직전) 화면에서 "기록 저장에 실패했습니다" 토스트가 표시됨 — 사용자에게 원인 불명의 에러로 보여 불안을 유발할 수 있음. (위치: 원인 확정 화면, 82% 진행 지점)
- [심각도: 사용성] "지금 시작하기"를 눌러 새로 진행했음에도 이전 세션의 "스쿼트·무릎" 진행 카드가 대시보드에 그대로 남아있어, 새로 시작한 감별과 이전 기록이 뒤섞일 가능성이 있어 보임(재검증 필요). (위치: 대시보드 재활 탭 "재활 진행 중" 카드)

## 최종 결과
- 도달한 화면/판정: danger 없이 정상 진행 — "족관절 배측굴곡 가동성 제한" 원인 확정 → 기초재활 1단계(월 앵클 모빌리티 등) 재활 루트 진입.
- 이 인물 입장에서 이 결과가 납득되는지: 네, 납득됨. 스쿼트를 배우면서 아직 발목 가동성이 충분하지 않아 무릎에 부담이 쏠린다는 설명이 "헬스는 했지만 크로스핏/스쿼트는 처음"인 배경과 잘 맞아떨어짐. "무릎이 아니라 발목이 원인"이라는 전개가 처음엔 의외였지만 이유 설명 덕분에 바로 이해됨.
