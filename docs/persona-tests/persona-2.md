# 페르소나 2: 35세 여 · 크로스핏 숙련(3년차), 워킹맘

## 인물 배경
매일 아침 WOD 참여. 최근 데드리프트 볼륨 늘리다 몸에 불편함. 바쁘고 급한 성격.

## 선택 과정 (왜 이렇게 골랐는지)
- 통증부위: 허리 — 최근 데드리프트 볼륨을 늘린 직후 생긴 불편함이라 가장 먼저 허리가 떠올랐음. 화면에는 "발목"이 기본 강조 표시되어 있었지만 실제 겪는 부위가 아니므로 무시하고 "허리"를 선택.
- 동작: 데드리프트 — 실제로 볼륨을 늘린 그 동작이므로 고민 없이 바로 선택.

## 진행 기록
1. 로그인 화면: "데모로 시작" 클릭 → 대시보드(기록 화면) 진입. 급한 성격이라 화면을 꼼꼼히 안 보고 바로 하단 "재활" 탭으로 이동.
2. 재활 홈: 이전에 진행하던 "스쿼트·무릎" 진행상황 카드가 떠 있었지만, 오늘은 새로 겪는 문제(허리)를 확인하고 싶어 "지금 시작하기"로 새로 시작.
3. 통증 부위 선택: "허리" 클릭. → **문제 발견**: 진입 시 "발목"이 파란 테두리로 이미 선택된 것처럼 표시되어 있었음. 이전 세션(스쿼트·무릎)과도 무관한 값이라 왜 발목이 기본 강조인지 이해가 안 됨. 급하게 넘기는 사용자라면 실수로 그대로 다음 단계로 넘어갈 위험 있음.
4. 동작 선택: "데드리프트" 클릭. 바로 선택, 문제 없음.
5. 감별 질문(통증 시점): "바닥에서 들어 올릴 때" 선택. 데드리프트 시작 구간(플로어에서 들어올리는 순간)이 가장 뻐근했던 기억과 일치해서 직관적으로 선택. 문제 없음.
6. 감별 질문(느낌): "허리가 당기고 뻐근해요"가 이미 파란 테두리로 강조되어 있었음. 본인 증상과 일치해서 그대로 클릭해 확정. (3번과 마찬가지로 "질문 진입 시 특정 보기가 미리 강조되어 보이는" 패턴이 반복됨 — 실제 선택인지 시각적 힌트인지 구분이 안 가서 헷갈렸음)
7. 직접 테스트(전굴·후굴): 바쁜 성격이라 "영상으로 보기" 안 누르고 텍스트 설명만 훑음. 데드리프트에서 앞으로 숙여 드는 동작이 가장 아팠던 기억이라 "앞으로 숙일 때만 아파요" 선택.
8. 원인 확정 화면: "데드리프트 허리 · 기술 오류" / "요추 굴곡 패턴 (Round Back)"로 진단. 위험 신호 체크리스트(부어있음/열감/양쪽 다리 저림)는 모두 해당 없어 그냥 눈으로 훑고 "재활 루트 보기" 클릭. → **문제 발견**: 화면 하단에 회색 토스트로 "기록 저장에 실패했습니다"라는 에러 메시지가 노출됨. 사용자 입장에서는 자신의 진단 기록이 저장되지 않았다는 뜻이라 당황스러움.
9. 재활 루트: 기초재활 1/4 단계 진입, "오늘의 준비운동"으로 캣-카우 등 운동 리스트 정상 표시. 각 운동에 "왜 이 운동인가" 설명 있음 — 원칙대로 이유가 붙어 있어 납득감 있음.

## 발견된 문제
- [심각도: 데이터] "재활 루트 보기" 클릭 직후 "기록 저장에 실패했습니다" 토스트 노출 — 위치: 원인 확정 화면 하단. 사용자의 감별 결과가 실제로 저장되는지 불확실해 신뢰도를 떨어뜨림.
- [심각도: 사용성] 통증 부위 선택 화면 진입 시 "발목"이 기본으로 파란 테두리 강조 표시됨 — 위치: 통증 부위 선택 화면. 실제 선택된 상태인지 단순 스타일인지 불명확해 급하게 넘기는 사용자는 잘못 진행할 위험.
- [심각도: 사용성] 감별 질문("어떤 느낌인가요?") 진입 시 "허리가 당기고 뼈근해요"가 이미 강조되어 있었음 — 위치: 챕터1 감별 질문 화면. 위와 동일한 패턴으로, 기본값처럼 보이는 강조 표시가 반복되어 사용자가 실제로 선택을 한 것인지 헷갈릴 수 있음.

## 최종 결과
- 도달한 화면/판정: danger 화면 없음 — cause 확정("데드리프트 허리 · 기술 오류" / 요추 굴곡 패턴 Round Back) → 재활 루트(기초재활 1/4 단계, 캣-카우 등 준비운동) 진입 완료.
- 이 인물 입장에서 이 결과가 납득되는지: 네. 데드리프트 볼륨을 늘린 뒤 들어올리는 순간·전굴 시 뻐근함을 느꼈다는 본인 경험과 "요추 굴곡 패턴" 진단, "들어올릴 때 허리가 말린다"는 설명이 자연스럽게 연결되어 이해가 됨. 다만 진단 직후 뜬 저장 실패 메시지 때문에 "내 기록이 남는 건가?" 하는 불안감은 남음.
