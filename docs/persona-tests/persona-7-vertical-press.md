# 페르소나 7: 29세 남 · 수직 프레스

## 프로필
- IT숙련도: 숙련 / 증상설명정확도: 부정확 / 증상민감도: 둔감 / 병원권유수용도: 수용적 / 크로스핏경력: 초보
- 시나리오: 고관절/사타구니 통증, 베이스라인(위험신호 없음)

## 진행 기록
1. 로그인 화면: "데모로 시작" 클릭 → 정상 진입, 기록 탭(캘린더)이 첫 화면으로 뜸. CLAUDE.md 안내대로 재활 탭으로 이동.
2. 재활 탭: 기존 진행 중인 재활(스쿼트·무릎, 기초 재활 단계)이 카드로 노출됨. 새 감별을 시작하기 위해 "지금 시작하기" 클릭.
3. 통증 부위 선택 화면: 선택지 8개 노출 — 무릎, 허리, 발목, 어깨, 고관절, 손목, 팔꿈치, 흉근. **"사타구니"라는 명칭은 전체 플로우에서 어디에도 존재하지 않음** (탭 텍스트 전수 확인). "고관절" 선택.
4. 동작 선택 화면: 고관절 선택 시 노출되는 동작은 **스쿼트, 런지, 데드리프트 3개뿐**. 수직 프레스는 목록에 없음.
5. 검증을 위해 뒤로 가서 다른 부위 확인:
   - 흉근 → 동작 선택지: 수평 프레스만 있음.
   - 어깨 → 동작 선택지: 스쿼트, 데드리프트, 풀업, 키핑, 로우, 수직 프레스, 수평 프레스. **수직 프레스는 오직 "어깨" 부위에서만 선택 가능.**
6. 고관절 → 스쿼트로 한 단계 더 진행해 하위 화면(감별 질문) 텍스트도 확인했으나 "사타구니" 단어는 전혀 등장하지 않음("통증이 언제 느껴지나요?" 질문만 노출).

## 발견된 문제
- [심각도: 데이터] **고관절/사타구니 통증 + 수직 프레스 조합이 앱 데이터에 존재하지 않음.** 통증 부위 "고관절"을 선택하면 스쿼트·런지·데드리프트만 동작 옵션으로 제공되고, 수직 프레스는 오직 "어깨" 부위에서만 선택 가능함. 임상적으로 오버헤드 프레스가 고관절 부하보다는 어깨 부하 동작이라는 점은 납득되지만, 배정된 테스트 시나리오(고관절/사타구니+수직프레스) 자체가 현재 앱 구조상 실행 불가능함 — 시나리오 매핑표와 실제 앱 데이터 간 불일치로 보임.
- [심각도: 데이터/오탈자] **"사타구니"라는 통증 부위 명칭이 앱 어디에도 존재하지 않음.** 최상위 통증 부위 선택지는 무릎/허리/발목/어깨/고관절/손목/팔꿈치/흉근 8종뿐이며, 하위 감별 질문 단계에서도 "사타구니" 단어는 노출되지 않음. 시나리오 지시문의 "앱에 있는 명칭 그대로 선택"이 전제하는 명칭이 실제로 없음.

## 최종 결과
- 배정된 cause/루트: **도달 불가 (BLOCKED)** — 고관절 선택 후 동작 목록에 수직 프레스가 없어 시나리오대로 진행할 수 없었음. 감별 질문·cause 판정·재활 루트 배정 단계에 도달하지 못함.
- 시나리오 의도와 일치 여부: **불일치.** 부정확한 증상설명이 판정 정확도에 미치는 영향은 검증하지 못함(감별 질문 자체에 도달하지 못했으므로). 이 페르소나 시나리오는 현재 앱 데이터 구조(부위×동작 매핑)와 맞지 않아, 시나리오 재배정(예: 어깨+수직프레스, 또는 고관절+스쿼트/런지/데드리프트 중 하나)이 필요해 보임.
