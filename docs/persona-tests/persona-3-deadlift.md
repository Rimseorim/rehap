## 진행 기록
1. 로그인 화면: "데모로 시작" 클릭 → 정상 진입. 첫 화면은 "기록" 탭(달력)이었음, 하단 네비게이션에서 "재활" 탭으로 이동.
2. 재활 홈: 기존에 진행 중이던 "스쿼트·무릎" 기초재활 카드가 있었음. "지금 시작하기"로 새 감별 플로우 시작.
3. 통증 부위 선택(10%): "무릎" 선택.
4. 동작 선택(30%): "데드리프트" 선택. (통증 부위 선택 직후 바로 동작 선택 화면으로 넘어감, 중간 단계 없음)
5. 감별 질문 1(30%): "통증이 언제 느껴지나요?" → "바가 무릎을 지나갈 때" 선택. (증상설명 부정확 페르소나 특성상 다소 애매하게 답할 법한 선택지)
6. 감별 질문 2(43%): "무릎 어느 쪽이 아픈가요?" (선택지: 앞쪽(슬개골 주변) / 바깥쪽) → "바깥쪽" 선택.
7. 직접 테스트(56%): **"데드리프트 셋업 무릎 정렬 테스트 (외측 통증용)"** 노출. 문구: "셋업 자세에서 무릎이 안쪽으로 쏠리는지 확인합니다. 바깥쪽 통증이 구조적 정렬 문제(밸거스) 때문인지, IT밴드 긴장 때문인지 구분합니다." 결과 선택지: "무릎이 발끝 방향 유지" / "무릎이 안쪽으로 쏠림" → 페르소나 특성(정렬 이상 있음)에 따라 "무릎이 안쪽으로 쏠림" 선택.
8. 원인 확정(82%): "근력 부족 — 고관절 외전근 약화 · 무릎 정렬 불안정"로 배정. 설명 문구에 "평소에도 무릎이 안쪽으로 쏠려 보이는 X자다리라면 근력 운동만으론 완전히 교정되지 않으니, 재활해도 통증이 지속되면 병원 진료를 받으세요"라는 안내 포함 — 구조적 밸거스(X자다리) 케이스를 명시적으로 인지하고 있음. 병원 권유 조건(부종/열감) 체크리스트도 함께 노출됨.
9. 재활 루트: "데드리프트 무릎 · 근력 부족 / 고관절 외전근 약화 · 무릎 정렬 불안정" 타이틀로 진입. 단계 구성은 "기초재활 → 회복테스트 → 재평가 → 운동복귀" 4단계로 표시됨(기획서 상 3단계 표현과 다르나 세분화된 형태로 추정). 기초재활 1단계 준비운동: 내전근 스트레칭·피리포르미스 스트레칭·밴드 사이드스텝·글루트브릿지 — 모두 고관절 외전근/정렬 강화 계열 운동으로 배정된 원인과 논리적으로 일치.

- fail 시 cause-b(정렬 문제)로 연결되는지: **예**. "무릎이 안쪽으로 쏠림"(fail) 선택 후 "근력 부족 — 고관절 외전근 약화 · 무릎 정렬 불안정" 원인으로 연결되었고, 설명에도 X자다리(밸거스)를 명시적으로 언급. 재활 루트의 운동 구성(고관절 외전근 강화 계열)도 이 원인과 일치.
