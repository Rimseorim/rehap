# 페르소나 4: 32세 남 · 크로스핏 숙련(5년차), 대회 준비 중

## 인물 배경
경력 5년차, 대회 준비 중이라 부상에 예민. 키핑 풀업 볼륨 늘리다 어깨 통증 발생.

## 선택 과정 (왜 이렇게 골랐는지)
- 통증부위: 어깨 — 페르소나 설정(키핑 풀업 볼륨 증가 후 어깨 통증)에 따라 선택
- 동작: 키핑 — "풀업"이 아니라 "키핑"을 선택. 스트릭트 풀업이 아니라 키핑 볼륨을 늘리다 생긴 통증이라는 설정에 맞춤

## 진행 기록
1. 통증 부위 선택 화면: "발목"이 클릭 없이 파란 테두리로 강조되어 있었음 (실제로는 "어깨"를 클릭해서 진행). → 문제 있음, 하단 기록
2. 동작 선택 화면(어깨): "풀업"이 클릭 없이 파란 테두리로 강조되어 있었음 (실제로는 "키핑" 클릭). → 문제 있음
3. "어깨 통증이 느껴지나요?": 실제로 통증이 있는 인물이므로 "네, 통증이 있어요" 선택. 이번엔 사전 강조 없었음.
4. "통증이 언제 느껴지나요?": "어느 정도 반복한 후"가 클릭 없이 파란 테두리로 강조되어 있었음. 볼륨을 늘리다 생긴 통증이라는 설정과 우연히 일치해 그대로 선택했지만, 클릭하지 않았는데 선택된 상태인 것 자체는 문제.
5. "능동 어깨 굴곡 검사" (직접 테스트): 대회 준비 중이라 몸 상태를 예민하게 체크하는 성격 반영 — 통증을 과소평가하지 않고 "올리는 중 통증이 있거나 귀 옆까지 안 올라가요"를 선택.
6. 원인 확정 화면: "가동성 부족 — 광배근·흉추 경직(어깨 굴곡 공간 부족)"으로 판정. 하단에 "기록 저장에 실패했습니다" 토스트 노출됨. → 문제 있음
7. 재활 루트: "키핑 어깨 · 가동성 부족" 루트로 진입. 기초재활 1단계에 밴드 랫 트랙션, 오버헤드 행잉 광배근 이완 등 제시. 각 운동에 방법·주의사항·"왜 이 운동인가" 설명이 포함되어 있어 원칙("이유를 붙인다")에 부합.

## 발견된 문제
- [심각도: 사용성] 통증부위/동작/감별질문 화면 진입 시 실제 클릭 없이 특정 선택지가 파란 테두리로 미리 강조되어 있음 — 3개 화면(통증부위 "발목", 동작 "풀업", 감별질문 "어느 정도 반복한 후")에서 재현. 이전 페르소나 3명이 보고한 것과 동일한 문제, 이번 페르소나에서도 동일하게 재현됨.
- [심각도: 데이터] 원인 확정 화면에서 "기록 저장에 실패했습니다" 토스트 노출 — 이전 페르소나 3명과 동일하게 재현.

## 최종 결과
- 도달한 화면/판정: danger 화면 없이 cause 판정("가동성 부족 — 광배근·흉추 경직") → 재활 루트(기초재활 1단계) 진입
- 이 인물 입장에서 이 결과가 납득되는지: 네, 납득됨. 대회 준비 중이라 통증을 과소평가하지 않고 정직하게 답했음에도 관절 부종·열감·팔이 갑자기 떨어지는 등 위험 신호는 없어 danger로 전환되지 않았고, 볼륨 증가 후 반복 중 통증 + 굴곡 시 통증이라는 응답이 광배근/흉추 경직으로 인한 가동성 부족 원인과 자연스럽게 이어짐. 다만 "기록 저장 실패" 토스트를 봤다면 이 인물은 대회 준비로 예민한 성격상 "내 기록이 안 남는 건가"라며 더 불안해했을 것.
