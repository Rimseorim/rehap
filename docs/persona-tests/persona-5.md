# 페르소나 5: 48세 남 · 크로스핏 초보(6개월차, 컴백)

## 인물 배경
20대 때 운동 경험 있으나 오래 쉬다 최근 재개. 로우 하다 손목/팔뚝 바깥쪽이 당기고 뻐근한 느낌. 디지털 기기에 서투른 세대 — 종이에 적는 게 더 익숙함.

## 선택 과정 (왜 이렇게 골랐는지)
- 통증부위: 손목 — 로우 동작 중 반복적으로 바를 잡아당기다 손목 쪽이 불편해서 가장 먼저 떠오른 부위로 선택.
- 동작: 로우 — 실제로 통증을 느낀 동작이 로우였으므로 그대로 선택.

## 진행 기록
1. 통증 부위 선택 화면: "손목"을 선택. → 문제 발견: 화면 진입 시 "발목"에 클릭하지 않았는데도 파란 테두리로 강조되어 있었음. 이 인물이라면 스마트폰 화면에 익숙하지 않아 "어? 내가 벌써 뭘 눌렀나" 하고 잠깐 멈칫할 법한 지점. 다행히 목록을 끝까지 읽고 "손목"을 직접 눌러 실수로 이어지지는 않았지만, 더 서두르는 성격이었다면 발목을 그대로 선택하고 넘어갔을 위험이 있음.
2. 동작 선택 화면: "로우"를 선택. → 동일한 문제 재현: "수직 프레스"가 클릭 전부터 파란 테두리로 강조되어 있었음. 역시 목록을 다 읽고 나서야 원하는 항목(로우)을 정확히 찾아 눌렀음.
3. 감별 질문(통증이 언제 느껴지나요): "어느 정도 반복한 후"를 선택 — 로우를 몇 세트 반복하다 보면 손목이 뻐근해지는 본인의 실제 패턴과 일치한다고 판단. 이 화면은 강조 버그 없이 정상 표시됨.
4. 감별 질문(손목 어느 쪽이 아픈가요): "손등 또는 팔뚝 바깥쪽 (신전근 쪽)"을 선택 — 바를 당길 때 손등 쪽, 팔뚝 바깥쪽이 당기는 느낌이라 이 항목이 가장 일치한다고 판단. 이 화면도 강조 버그 없음.
5. 직접 테스트(저항성 손목 신전 검사): 화면에 나온 대로 책상에 팔뚝을 올리고 반대 손으로 손등을 눌러 저항하는 셀프 테스트 지시를 읽음. "저항하는 동안 손등·팔뚝 바깥쪽에 통증이 재현돼요"를 선택 — 실제로 평소 느끼던 통증과 같은 위치였음. 이 인물 입장에서 텍스트로 된 3단계 지시가 다소 빽빽해 보였지만("영상으로 보기" 버튼이 있어 도움이 될 만함), 번호가 매겨져 있어 순서를 따라가기는 어렵지 않았음.
6. 원인 확정 화면: "손목 신전근 건병증(손등·팔뚝 바깥쪽 통증)" · 과부하 원인으로 판정. 위험 신호 체크리스트(관절이 눈에 띄게 부어있어요 / 만지면 열감이 느껴져요) 모두 해당 없음 — 이 인물은 붓기나 열감은 없다고 판단해 병원행 없이 재활 루트로 진행. → 문제 재현: 화면 하단에 "기록 저장에 실패했습니다" 토스트 메시지가 떴음. 이전 페르소나 4명 전원과 동일하게 재현.
7. "재활 루트 보기" 클릭 → 기초 재활 1단계 화면 도달. "전완 신전근 폼롤러 릴리즈"(양측 각 60초·2세트), "손목 원형 돌리기" 등 운동이 번호가 매겨진 단계별 방법과 "왜 이 운동인가" 설명 섹션과 함께 제시됨. 진행 단계 표시(1/4)와 4개 탭(기초재활/회복테스트/재평가/운동복귀) 구조가 한눈에 들어와, 이 인물 입장에서도 "지금 내가 어디 단계에 있는지"는 비교적 명확하게 이해할 수 있었음.

## 발견된 문제
- [심각도: 데이터] "원인 확정" 화면에서 "기록 저장에 실패했습니다" 토스트 발생 — 원인 확정 단계(재활 루트 보기 직전 화면), 이전 4개 페르소나 테스트에서도 동일하게 재현(5/5 누적).
- [심각도: 사용성] 통증부위 선택·동작 선택 화면 진입 시 사용자가 클릭하지 않은 특정 선택지(이번엔 "발목", "수직 프레스")가 파란 테두리로 미리 강조되어 표시됨 — 이전 4개 페르소나 전원 재현(5/5 누적). 이번 페르소나는 다행히 목록을 끝까지 읽는 성격이라 오선택으로 이어지지는 않았으나, "화면 조작에 서투른 중년" 설정 특성상 "이미 뭔가 눌려 있다"고 착각해 그대로 다음으로 넘어갈 뻔한 위험 요소로 실제 체감됨. 특히 이 나이대 사용자는 포커스/호버 상태와 실제 선택 상태의 시각적 구분에 익숙하지 않아 영향이 클 수 있음.

## 최종 결과
- 도달한 화면/판정: danger 화면 없이 정상 진행 — "로우 손목 · 과부하" → "손목 신전근 건병증(손등·팔뚝 바깥쪽 통증)" cause 판정 → 기초 재활 1단계(전완 신전근 폼롤러 릴리즈, 손목 원형 돌리기 등) 재활 루트 도달.
- 이 인물 입장에서 이 결과가 납득되는지: 네. 오랜만에 운동을 재개하며 로우 동작을 반복하다 손목/팔뚝이 뻐근해진 상황과 "과부하"라는 원인 설명, 그리고 폼롤러로 신전근을 풀어주는 첫 단계 운동이 자연스럽게 연결되어 이해하기 쉬웠음. 다만 "기록 저장 실패" 토스트를 보고 "어? 이거 지금까지 한 거 저장 안 된 거 아냐?" 하고 잠깐 불안해했을 법함.
