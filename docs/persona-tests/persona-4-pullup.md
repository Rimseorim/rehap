# 페르소나 4: 27세 여 · 풀업

## 프로필
- IT숙련도: 미숙 / 증상설명정확도: 부정확 / 증상민감도: 예민 / 병원권유수용도: 거부감 / 크로스핏경력: 초보
- 시나리오: 어깨 통증, Drop Arm 양성(위험신호) — 안전 핵심 시나리오

## 진행 기록
1. 로그인 화면: "데모로 시작" 링크가 화면 하단에 작게 있어 IT미숙 페르소나가 바로 찾지 못하고 화면을 훑어보는 데 시간이 걸림(카카오/네이버/구글 로그인 버튼이 훨씬 눈에 띔) → 클릭해 진입
2. 진입 직후 "기록" 탭(캘린더/오늘 기록)이 첫 화면으로 표시됨 → 하단 탭에서 "재활" 탭으로 이동
3. 재활 홈: 기존에 진행 중이던 "스쿼트·무릎" 재활 카드가 표시됨(다른 페르소나 세션의 잔여 상태로 추정) → "지금 시작하기"로 신규 감별 시작
4. 통증 부위 선택: "어깨" 클릭
5. 동작 선택: "풀업" 클릭
6. 챕터1 감별질문 "어깨 통증이 느껴지나요?" → "네, 통증이 있어요" 선택(시나리오대로 양성)
7. "통증이 언제 느껴지나요?"(빈도/양상, 위험신호 아님) → 병원권유거부감 성향 반영해 축소 답변으로 "어느 정도 반복한 후" 선택(가장 덜 심각해 보이는 선택지)
8. 챕터2 직접 테스트 "능동 어깨 굴곡 검사" → "통증 없이 귀 옆(180도)까지 올라가요" 선택(위험신호 아님, 거부감 성향 반영해 정상으로 축소 응답)
9. "데드 행(Dead Hang) 부하 검사" → "15초 매달리는 동안 통증이 없어요" 선택(동일 사유로 정상 응답)
10. "코어-상지 분리 검사(Lumbar Lock)" → "팔을 들어도 허리가 벽에서 안 떨어져요" 선택(동일 사유)
11. **원인 확정 화면 도달** — "컨디셔닝 부족 / 특이 소견 없음" 결과와 함께 빨간 경고 박스에 3개 항목("관절이 눈에 띄게 부어있어요", "만지면 열감이 느껴져요", **"저항할 때 팔이 갑자기 뚝 떨어져요"**)이 표시됨. "저항할 때 팔이 갑자기 뚝 떨어져요"는 Drop Arm에 해당하는 문구.
    - **이 3개 항목을 클릭해보았으나 아무 반응이 없었음(체크박스/버튼이 아닌 정적 안내 텍스트)**. 즉 이 시점까지 진행된 질문/테스트 흐름 전체(6~10단계)에 Drop Arm 여부를 실제로 응답할 수 있는 인터랙티브 질문이 단 하나도 없었음.
    - 박스 하단에 "위 항목에 해당된다면 재활 전 전문의 진단을 먼저 받으세요"라는 안내 문구만 있고, 이를 "예/아니오"로 답변해 분기시키는 UI 요소는 없음.
12. "재활 루트 보기" 클릭 → 위험신호 확인 절차 없이 곧바로 "기초재활" 프로그램(Chest Stretch, Thoracic Rotation Stretch 등)으로 진입.

## 안전 검증 결과
- 위험신호(Drop Arm) 질문 도달 및 양성 응답 경로: **도달하지 못함.** 챕터1(통증 유무/양상), 챕터2(능동 굴곡 검사, 데드 행 검사, 코어-상지 분리 검사) 어디에도 Drop Arm(저항 시 팔이 뚝 떨어짐)을 직접 응답하는 질문이 없었음. 원인 확정 화면에 텍스트로만 "저항할 때 팔이 갑자기 뚝 떨어져요"가 노출되지만 클릭 불가능한 정적 경고문이라 사용자가 "그렇다"고 답할 방법 자체가 없음.
- danger 화면 노출 여부: **아니오**
- danger 화면이 뜨지 않음. 화면 문구 인용 불가(도달하지 않음).
- **놓친 경로/조건**: 어깨+풀업 감별 흐름에서 챕터1의 "통증 느껴지나요"→"네", 챕터2의 3개 신체 검사(능동 굴곡/데드 행/코어-상지 분리) 모두 "정상"으로 응답하면, Drop Arm(회전근개 완전파열 의심 신호)을 실제로 겪고 있는 사용자라도 이를 입력할 문항이 전혀 제공되지 않은 채 "컨디셔닝 부족"으로 원인이 확정되고 그대로 기초재활 운동 루트(가슴 스트레칭 등 능동 스트레칭 포함)로 안내됨. 원인 확정 화면의 경고 박스는 정적 텍스트일 뿐 실제 분기 로직에 연결되어 있지 않은 것으로 관찰됨.

## 발견된 문제
- **[심각도: 안전] 최상위** — 풀업×어깨 감별 흐름에 Drop Arm(회전근개 파열 의심) 위험신호를 사용자가 직접 응답할 수 있는 질문이 없음. 원인 확정 화면에 경고 문구(관절 부종/열감/Drop Arm)가 텍스트로만 노출되고 클릭 불가능해 실질적인 분기 트리거가 되지 못함. 그 결과 실제로 Drop Arm 증상이 있는 사용자도 danger 화면 없이 "컨디셔닝 부족" 원인으로 배정되어 능동 스트레칭이 포함된 기초재활 운동을 시작하게 됨 — 프로젝트 핵심 원칙 "위험 신호는 즉시 멈춤"에 정면으로 위배. — 원인 확정 화면(어깨·풀업 챕터, 82% 진행 지점)
- [심각도: 사용성] "데모로 시작" 링크가 화면 하단에 작은 텍스트 링크로만 존재해 IT숙련도 낮은 사용자가 빠르게 찾기 어려움 — 로그인 화면
- [심각도: 사용성] 재활 홈 진입 시 이전 세션(다른 부위/동작)의 "진행 중" 카드가 그대로 남아 있어 신규 감별을 시작하려는 사용자가 혼란을 겪을 수 있음("지금 시작하기"와 "이어하기"의 차이가 명확히 구분되지 않음) — 재활 홈
- [심각도: 데이터] 원인 확정 화면 하단에 "기록 저장에 실패했습니다"라는 버튼(또는 상태 문구)이 노출됨 — 실제 저장 실패인지, 버튼 라벨 자체의 오류인지 불명확하나 사용자에게 불안감을 줄 수 있는 문구 — 원인 확정 화면

## 최종 결과
- 배정된 결과(danger 안내 or cause/루트): "풀업 어깨 · 컨디셔닝 부족" 원인 확정 → 기초재활 루트(1/4단계, Chest Stretch 등 준비운동부터 시작) 진입
- 시나리오 의도와 일치 여부: **불일치.** 시나리오는 Drop Arm 양성 응답을 통해 danger 화면(병원 안내)이 떠야 했으나, 해당 위험신호를 입력할 질문 자체가 흐름에 없어 재활 루트로 빠짐 — 이번 테스트의 최우선 안전 이슈로 기록.
