# 페르소나 5: 38세 남 · 키핑

## 프로필
- IT숙련도: 숙련 / 증상설명정확도: 정확 / 증상민감도: 예민 / 병원권유수용도: 수용적 / 크로스핏경력: 초보
- 시나리오: 손목 통증, 안정 시 저림 지속(위험신호) — 수용적 기준선

## 진행 기록
1. 로그인 화면: "데모로 시작" 클릭 → 첫 화면이 "기록" 탭으로 진입(캘린더+오늘 기록). CLAUDE.md 안내대로 "재활" 탭으로 이동 필요.
2. 재활 탭: "재활 진행 중 · 스쿼트·무릎 · 기초 재활 단계" 카드가 이미 표시됨(이전 세션 잔존 상태로 추정) → "지금 시작하기" 클릭해 새 감별 시작.
3. 통증 부위 선택 화면(10%): "손목" 클릭 → 정상 진행, 진행바 갱신됨.
4. 동작 선택 화면(30%): 손목 칩이 상단에 유지된 채 "데드리프트/풀업/키핑/로우/수직 프레스/수평 프레스" 6개 옵션 표시 → "키핑" 클릭.
5. 챕터1 감별 질문(30%): "통증이 언제 느껴지나요?" — "운동 시작하자마자 / 어느 정도 반복한 후 / 쉬는 중에도" 3지선다. 페르소나 지시대로 안정 시 지속을 의미하는 "쉬는 중에도" 선택.
6. 즉시(47%) 주의 화면으로 전환. 추가 질문 없이 바로 danger 화면 도달 — 질문 1개만으로 위험신호 감지, 손목/저림 관련 별도 문항은 존재하지 않았음(진행 기록 참고).

## 안전 검증 결과
- 위험신호 질문 존재 여부 및 경로: "통증이 언제 느껴지나요?" 문항의 3번째 선택지("쉬는 중에도")가 위험신호 트리거 역할. 저림/붓기를 직접 묻는 별도 문항은 없었고, danger 화면 텍스트 안에서 "저림·붓기"를 사후적으로 언급함.
- danger 화면 노출 여부: **예** — 정상적으로 노출됨.
- danger 화면 문구 원문:
  - 헤더: "주의" / "지금 바로 운동을 멈추세요"
  - 본문 카드: "병원 진료가 필요합니다 / 안정 시에도 손목 통증이 지속되거나 저림·붓기가 있으면 인대·연골 손상이 의심됩니다. / 정형외과 또는 스포츠의학과 진료를 권장합니다. 통증 위치(엄지 쪽/새끼 쪽/가운데)를 기록해 방문하세요."
  - 하단 안내: "증상이 안정되고 안정 시 통증이 없어지면 앱으로 돌아와 다시 감별해보세요. / 재활 루트는 전문가 진료 후 병행할 수 있습니다."
  - 버튼: "처음으로 돌아가기"

## 발견된 문제
- [심각도: 사용성] 로그인 데모 진입 시 첫 화면이 "기록" 탭(캘린더)으로 뜨며, 이미 "스쿼트·무릎 기초 재활 진행 중" 카드가 남아 있음 — 새 사용자/새 세션 감별 흐름 진입 전에 이전 진행 상태가 혼재되어 보임. 재활 탭 진입 후에도 "지금 시작하기"를 눌러야 새 감별이 시작되는데, 이 상태 정리가 명확하지 않아 처음 쓰는 사용자는 "이어하기"와 "새로 시작"의 차이를 헷갈릴 수 있음. — 재활 탭 진입 카드
- [심각도: 데이터] 손목 통증의 위험신호 감별이 "통증이 언제 느껴지나요?"라는 단일 3지선다 문항에만 의존하며, "저림"을 직접 묻는 문항이 없음(danger 화면 문구에서만 사후 언급). 저림 없이 단순히 "쉬는 중에도 약간 뻐근함" 정도인 사용자도 동일하게 병원행 danger 화면으로 즉시 전환될 소지가 있어 과민 분기 가능성 — 감별 질문 화면(챕터1)
- [심각도: 안전] 다른 3지선다 응답("운동 시작하자마자", "어느 정도 반복한 후")에 대해서는 이번 세션에서 확인하지 않음 — 위 두 응답의 후속 분기(구조적/과부하 등)는 별도 검증 필요.

## 최종 결과
- 배정된 결과: danger 안내 화면("병원 진료가 필요합니다")
- 시나리오 의도와 일치 여부: **일치**. 손목/키핑 경로에서 "쉬는 중에도" 응답 시 danger 화면이 정상적으로 즉시 노출됨을 확인. 페르소나4(풀업, 안정 시 통증 지속 경로에서 danger 미노출 버그)와 달리, 이번 손목 경로는 정상 동작함 — 즉 danger 화면 미노출 버그는 풀업 경로 국한 문제이거나, 최소 손목·키핑 조합에서는 재현되지 않음.
