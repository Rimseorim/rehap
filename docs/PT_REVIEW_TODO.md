# 임상 검수(PT) 확인 목록

PT 임상 검수 때 함께 확인할 항목을 모은다. 확인이 끝나면 결과와 날짜를 적고 줄을 지우지 않는다.
문구 표기 쪽 ★ 항목의 정본은 `docs/VIDEO_REVIEW_RULES.md §일괄 적용한 표기` 이고, 여기에는 목록만 둔다.

## 문구·해석 (2026-10-05 문구 일괄 수정에서 나옴)

| 항목 | 확인할 것 | 결과 |
|---|---|---|
| PAILs/RAILs 라벨 풀이 | "[PAILs: 끝에서 밀며 버티기]·[RAILs: 더 깊이 당기며 버티기]" 가 환자용으로 맞는지 | |
| 양성 풀이 | "양성(증상이 나타남)" 표기가 맞는지 | |
| "우울" → "내리기" | 원문 "우울"을 "내리기"로 해석해 고친 것이 맞는지 | |
| 손목 신전근 서술 | 손목 신전근이 배측굴곡을 제한한다는 서술이 맞는지 | |
| "골반의" 보충 | 문구에 보충한 "골반의" 가 뜻을 바꾸지 않는지 | |
| 손목 편심성 운동명 | 운동명에서 "편심성"을 빼고 cue 에 보충한 것이 맞는지 | |

## 재검사 근거 (2026-10-06 협업자 답변 「재검사 질문 답변」에서 나옴)

| 항목 | 확인할 것 | 결과 |
|---|---|---|
| 룸바락 재검사 3종 (`test-shoulder-lumbarlock-rom`·`-core`·`-scapula`) | 신뢰도·타당도를 검증한 논문을 찾지 못했다(코칭 현장 평가법, 영어로는 back-to-wall shoulder flexion 이 가장 가깝다). 그대로 쓰기로 결정했으니 임상적으로 써도 되는지 확인한다. `docs/RETEST_VALIDATED_TESTS.md §B` 는 Seated Wall Angel test 와 거의 같다고 적었으므로 두 판단을 함께 본다. "lumbar-locked rotation"(네발 자세 흉추 회전)은 다른 검사이므로 근거로 쓰지 않는다 | |
| 애플리 스크래치 재검사 (`test-shoulder-apleys-retest`) | 좌우 차이 비교 검사이고 신뢰도 수치가 부족하다. 통과 기준(좌우 차이 3cm 이내 등)을 정할지 확인한다 | |
