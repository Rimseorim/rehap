# 선별검사·직접테스트·회복테스트 내용-원인 일치 검토 (2026-06-14~)

53개 고유 검사(직접테스트+회복테스트) + 선별검사 분기 로직 전체를,
통증부위 → 동작 순서(앱 표시 순서)로 1차 확인 → 반박 → 재확인(3회) 진행.

순서 기준:
- 통증부위: 무릎 → 허리 → 발목 → 어깨 → 고관절 → 손목 → 팔꿈치 → 흉근

lunge·press-h·press-v/허리(플랭크), squat/허리(흉추신전), row/허리(토터치), lunge/허리(ASLR)

결과: 12개 고유 검사 모두 cause.description과 메커니즘 일치 확인.
- #1 맥켄지 신전검사(4개 동작 공유): press-h/press-v(오버헤드→요추신전 패턴)는 직접 매치,

## 어깨 (스쿼트 → 데드리프트 → 풀업 → 키핑 → 로우 → 수직프레스 → 수평프레스) — 검토 완료

5개 원인(cause-dp, case1~4)이 7개 동작에 공유 구조로 적용됨 (이름·태그·재활운동 동일, 진입 검사만 동작별로 다름).

| 동작 | 1차 검사 (pass→2차 / fail→) | 2차 검사 (pass→ / fail→) | 판정 |
|---|---|---|---|
| 스쿼트 | 통증호(arc) / dp | 외회전가동성(ext-rot): case4 / case3 | 일치 |
| 데드리프트 | 통증호(arc) / dp | 내회전저항(int-rot): case2 / dp | 일치 (수정 완료) |
| 풀업 | 능동굴곡(flex) / case1 | 데드행부하(hang): case2 / dp | 일치 |
| 키핑 | 능동굴곡(flex) / case1 | 후방신전(ext): case2 / case3 | 일치 |
| 로우 | 통증호(arc) / dp | 수평외전저항(h-abd): case2 / dp | 일치 |
| 수직프레스 | 능동굴곡(flex) / case1 | 빈캔(empty-can): case2 / dp | 일치 |
| 수평프레스 | 통증호(arc) / dp | 수평내전저항(h-add): case2 / dp | 일치 (수정 완료) |

case2/3/4는 공유 질문분기(룸바락/Apley's Scratch 검사, 7동작 동일 문구)로도 추가 도달 가능.

원천 자료: `어깨 재활 프로그램.txt` (FN/DP/DN 분류 체계). cause-dp/case1~4 정의 및 stage-1 재활운동이 해당 문서 섹션2 운동 목록과 일치 확인.
"쉬는 중에도 아픔" → danger(Drop Arm/회전근개 파열 경고) 분기도 7동작 동일 적용 — 프로젝트 원칙5(위험신호 즉시 멈춤)와 부합.

### 수정 완료
- **press-h q1.sub**: "오버헤드 프레스 중 찝히거나..." → "수평 프레스 중 찝히거나..."로 수정.
  사유: press-v(오버헤드프레스) 문구를 복붙한 흔적. press-h는 수평프레스(벤치프레스류)로 오버헤드 동작이 아님.
- **press-v cause-case1**: tag "관절 가동범위 제한"→"가동성 부족", name "광배근·흉추 신전 가동범위 제한 (견관절 굴곡 공간 부족)"→"광배근·흉추 경직 (어깨 굴곡 공간 부족)"로 수정.
  사유: 나머지 6개 동작과 라벨 통일. 기존 name에 "신전"과 "굴곡"이 혼재해 의미가 불명확했음.
- **squat cause-case1**: description "등 근육이나 등 중간이 굳어 있으면... 허리가 꺾이면 공간이 부족해 나타나는 보상입니다" → "광배근이나 흉추가 굳어 있으면... 허리가 꺾이는 것은 공간이 부족해 나타나는 보상 패턴입니다"로 수정, priority_note도 "광배근 이완 → 흉추 가동성 → 패턴 통합 순으로 진행합니다"로 통일.
  사유: 6/7 동작과 표현 통일 (더 구체적인 표현으로 정리).
- **deadlift test-shoulder-int-rot**: pass_next를 cause-case1 → cause-case2로 변경.
  사유: int-rot은 회전근개 저항/근력 검사로 "통과(pass)"가 광배근·흉추 경직(case1, 가동성 문제)을 시사하지 않음. 다른 동작의 "2차검사 pass→case2(코어-상지 분리실패)" 패턴과 일치시킴. case1은 기존 공유 질문분기로도 도달 가능해 손실 없음.

**어깨 결론**: 35개 원인 매핑(7동작×5원인) 검토 완료, 이슈 4건 모두 수정 완료. 보류 없음.
