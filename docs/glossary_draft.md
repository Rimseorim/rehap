| 슬개대퇴 | 무릎뼈와 허벅지뼈가 맞닿는 부분 |

| 관절활액 | 관절 안을 채워 뼈 사이 마찰을 줄이는 윤활액 |
| TFCC | 손목 새끼손가락 쪽에 있는 삼각형 모양의 연골 구조물 |
| FAI | 고관절 뼈가 움직임 중에 서로 맞닿아 걸리는 증상 |
| valgus | 무릎이 안쪽으로 무너지는 현상 |
