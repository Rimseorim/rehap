# 영상 검수 규칙

영상 검수판(Artifact)과 함께 전달하는 규칙 문서. 검수 이어받는 사람은 이 기준으로 판단할 것.

## 수정 범위 규칙

- **사실관계·해부학적 오류** (동작 방향, video_url 오배정 등) → 같은 id를 쓰는 **모든 중복 인스턴스**에 동일 적용
- **문구·스타일 수정** (표현 방식, 각도→패턴 언어 전환 등) → **검토 중인 그 인스턴스에만** 적용, 다른 동작의 중복 인스턴스는 안 건드림

## "검수 완료" 기준

- 제목/영상 링크만 확인하고 완료 표시 금지
- steps·note·passText·failText 본문까지 실제로 다 확인했을 때만 완료

## 영상 신뢰성 검증

- 영상 내용만 보고 판단하지 않는다 — 순서·방법이 의심되면 임상 자료(WebSearch로 Physiopedia, Orthofixar 등 근거 자료)로 교차 검증 후 수정
- video_url이 여러 다른 이름의 테스트에 동일하게 붙어 있으면 복붙 오류 의심 신호 — 전수 grep으로 재사용 현황 확인

## 용어 규칙 (본문)

- 사용자 노출 필드(name/purpose/note/why/steps)의 의학 전문용어는 쉬운 말 + 괄호 안 원어 병기
  - 예: 장요근 → "고관절 앞쪽 근육(장요근)", 고관절 외전근/중둔근 → "엉덩이 옆 근육(중둔근)"
- "엉덩이"는 둔근(뒤쪽) 어감이 강해 몸 앞쪽 부위 설명엔 쓰지 않는다
- `target_area` 등 화면에 렌더링되지 않는 내부 메타데이터 필드는 치환 대상에서 제외 (렌더링 여부는 코드에서 `.필드명` 접근 확인)

## 영상 링크 규칙

- 기준은 영상 전체 길이가 아니라 **"검사 동작이 실제로 나오는 시점이 앞부분에서 얼마나 떨어져 있는가"**다
- 검사 동작이 시작되기까지 인트로·무관한 설명이 길게 낀다면(대략 15~20초 이상) 그 지점으로 **타임스탬프(`&t=초`)를 붙여서** 링크한다
  - 예: `...&t=45`, `...&t=145`
- 동작이 영상 앞부분(10초 안팎)에 바로 나오면 영상이 1분을 넘더라도 타임스탬프 불필요
- 반드시 실제로 재생해서 동작이 나오는 지점을 확인한 뒤 붙인다 — 길이만 보고 추정하지 않는다

## 용어 규칙 — 판단 기준

의학 전문용어를 쉬운 말로 바꿀지 판단하는 기준 3가지: (1) 사용자 노출 필드에 있는가 (`target_area`처럼 렌더링 안 되는 필드는 제외), (2) 이미 쉬운말이 붙어 있는가(예: "무릎 앞쪽(슬개건)"은 이미 통과, 안 붙어있으면 대상), (3) 일반인이 위치·역할을 짐작 못 하는 이름인가 (관절·부위 자체 이름인 무릎·어깨·허리 등은 제외). 위 기준에 걸리면 영상 검수 중 발견한 자리에서 바로 고친다 (범위 유보 없음).

## 테스트명(제목) 규칙

- 형식: **"[원어] 검사 — [확인 대상]"** — 고유명사(인명)나 약어를 맨 앞에 그대로 쓰고, 대시 뒤에 이해하기 쉬운 설명을 붙인다. 괄호를 추가로 쓰라는 뜻이 아니라 이 순서·구분자로 통일하라는 뜻
  - 예: "FADIR 검사 — 고관절 앞쪽 충돌 확인", "토마스 검사 — 고관절 앞쪽 근육 긴장 확인"
  - 여기서 "원어"란 FADIR·TFCC·ASLR 같은 약어, 토마스·코젠 같은 인명(고유명사)을 가리킴 — 그 자체로는 뭘 확인하는 검사인지 알 수 없는 이름
- **대시 뒤에는 확인 대상(무엇을 확인하는지)만 남긴다 — 동작 설명(어떻게 하는지)은 넣지 않는다.** 포인트는 **짧고 한눈에 보이는 것** — 동작 설명까지 넣으면 길어져서 한눈에 안 들어옴. 동작 설명은 steps에 이미 있어 제목에서는 중복. 예: "싱글레그 힐레이즈 검사 — 아킬레스건 부하 확인" (O, 짧고 바로 보임), "…한 발로 뒤꿈치 들어올려 아킬레스건 부하 확인" (X, 길어서 한눈에 안 들어옴)
- "검사" 명칭 통일 — "테스트" 대신 **"검사"**를 쓴다 (파일 전체 name 필드 기준 검사 125건 > 테스트 31건, 기존 규칙 예시도 전부 "검사")
- 구분자는 대시(`—`)로 통일 — 괄호 `()`로 설명을 붙이던 기존 표기도 대시로 정리
- 이 형식을 고른 이유: "쉬운 설명이 맨 앞에 오게" 방식은 검사마다 자연스러운 설명 문구를 새로 지어야 해서 품질 편차가 크고 나중에 일괄 처리가 어려움. 반면 "원어 + 대시 + 설명"은 기계적으로 일관 적용 가능하고, FADIR·토마스·코젠 같은 용어는 PT나 이미 아는 사용자에게 빠른 인식 키워드로도 쓰인다
- 주의: 한글로 표기했다고 쉬운 말이 되는 게 아니다 — "토마스 테스트"는 한글이어도 인명이라 그 자체로는 뭘 확인하는지 알 수 없음. 판단 기준은 언어가 아니라 "맨 앞 단어가 뭘 하는 검사인지 설명하는가"
- 인명·고유명사는 **영문이 아닌 한글 표기(토마스, 코젠 등)로 통일** — 영어로 적어도 이해도는 올라가지 않고(어차피 이름이라 뜻을 알 수 없음), 나머지 한국어 문장과 어울리지 않음. 검색·인지 목적은 한글 표기로도 충분

## 원인명 규칙

- **"[원어] 검사 — [확인 대상]" 형식은 검사 제목 전용이다.** 원인명은 검사 결과(결론)라 "검사"가 들어갈 자리가 없으므로 이 형식을 쓰지 않는다
- 원인명은 **쉬운 말 + 괄호 원어**로 쓴다 (본문 용어 규칙과 동일)
  - 예: 족관절 배측굴곡 가동성 제한 → 발목 굽힘(배측굴곡) 제한 (검사 이름과 동일하게)
  - 예: 만성 외측 발목 불안정 → 만성 바깥쪽 발목 불안정
- 굳어진 진단명(~증후군, 건병증, TFCC 손상 등)은 그대로 두고, 이해가 어려우면 괄호로 쉬운 설명을 붙인다
  - 예: 발목 전방 충돌 증후군 → 발목 앞쪽 충돌 증후군 / 슬개대퇴 증후군 → 슬개대퇴 증후군(무릎 앞쪽 통증)
- 원인 카드에는 태그 칩(가동성 부족·과부하 등)이 이미 붙어 있으므로 원인명은 짧게 유지한다
- 원어를 그대로 쓰는 것은 위반이다 — 원인명도 사용자에게 그대로 노출되는 필드다

## 재활 운동 규칙

### 운동명

- 운동명은 **표준명 그대로** 쓴다. 표준명이란 그 운동을 흔히 부르는 이름이다 (예: 클램셸, 글루트 브릿지, 고블릿 스쿼트, 데드버그). 검사 제목처럼 "원어 + 대시 + 설명" 형식으로 새로 만들지 않는다
- 대시(—)·괄호·콜론 뒤의 맥락·목적·단계 표기("무부하 패턴 확인", "최종 통합 테스트", "→ 점진", "(짝수날)" 등)는 **이름에서 삭제한다**
  - 삭제 전에 그 내용이 why·큐·방법에 이미 들어 있는지 확인한다. **없으면 why에 한 문장으로 보충한 뒤 삭제한다**
  - 예: "맨몸 스쿼트 — 랙 포지션 팔 자세 확인" → "맨몸 스쿼트" (팔 자세는 방법·큐에 이미 있음)
  - 마지막 단계임은 화면의 "진행 단계 N/4" 배지가 알려 주므로 이름에 "최종"을 따로 적지 않는다
  - "목적이 이미 들어 있다"의 기준: 대시 뒤 내용의 뜻이 같은 운동의 why·큐·방법 중 한 곳에 문장으로 적혀 있으면 통과. 방법(how)에만 있는 동작 설명(예: 소범위 스윙의 할로우·아치)은 why에 옮기지 않는다 — 그 운동의 목적이 아니라 동작 자체이기 때문
  - 같은 원인·같은 단계 안에서 이름 뒤 꼬리표만 다른 짝(예: 로우 허리 원인 b의 "얕은 각도"·"깊은 각도", 덤벨 RDL "와이드 스탠스"·"정상 스탠스")은 꼬리를 지우면 이름이 겹치므로 짝 단위로 따로 결정한다
    - 결정 예: 로우 허리 원인 b는 "PVC 벤트오버 로우 (상체 45도)" / "PVC 벤트오버 로우 (상체를 더 깊이)". 구분 표기는 괄호로 남기되 기준이 보이게 쓴다("얕은/깊은"처럼 기준 없는 상대 표현 금지). 각도가 사람마다 달라지는 단계는 수치를 확정하지 않는다
  - "2단계와 동일" 같은 번호 참조는 화면에 운동 번호가 보이지 않으면 뜻이 통하지 않으므로 "앞 운동에서 …"로 쓴다
  - "소범위 스윙"은 표준명으로 그대로 둔다 (작은 폭으로 앞뒤로 흔드는 스윙)
- 표기: 할로우(hollow)를 "허로우"로 쓰지 않는다 (2026-09-24 전수 수정)
- 같은 운동을 동작별로 복제한 이름("…오버헤드 락아웃 특화" 등)은 하나로 합친다. 동작별 차이는 why·방법에서 설명한다
- **한글/영어 통일**: 사용자가 검색했을 때 더 잘 나오는 쪽으로 통일한다. 기본은 한글이고, 영어가 훨씬 잘 나오는 것만 예외로 둔다
- 이름 안의 의학·해부 용어는 쉬운 말(원어)로 쓴다. 예: "종아리 스트레칭 (비복근)"은 통과, "밴드 거골 후방 견인 스트레칭"은 대상

### 용어 표기

- **의학·해부 용어**는 쉬운 말(원어): "날개뼈 벌리기(프로트랙션)", "고관절 앞쪽 근육(장요근)"
- **운동·기술 용어**는 용어(쉬운 말): "랙 포지션(바를 어깨 앞에 얹은 자세)", "락아웃(팔을 완전히 편 마지막 자세)"
- 원칙은 **사용자 대부분이 아는 쪽을 앞에 둔다.** 어느 쪽인지는 "박스에서 코치가 설명 없이 쓰는가"로 판단한다 (프로트랙션은 코치가 써도 대부분 뜻을 모르므로 의학·해부 용어 쪽)
- 괄호 풀이는 **짧게(대략 12자 안팎)** 쓴다. 길어지면 문장이 끊겨 용어를 아는 사람에게도 걸린다
- 괄호는 **필드마다 첫 등장**에 붙인다 (why·큐·방법은 각각 따로 읽히므로)
- "견갑골"·"어깨뼈"는 **"날개뼈"로 통일**한다 (검사 문구 포함)
- **운동 방식 전문용어(등척성·등장성·편심성 등)는 이름에 쓰지 않고, how·cue에 쉬운 말로 풀어 쓴다.** 사용자가 모르는 말이라 이름에 두면 뜻이 안 통하고, 지우면 운동 방식 정보가 사라지므로 how·cue에 그 정보가 들어 있어야 한다
  - 등척성 → "제자리에서 힘만 주며 버티기" (예: 월 프레스 — "벽을 밀며 3초 버티세요. 몸은 제자리에 둡니다")
  - 등장성 → "관절이 움직이면서 힘 쓰기"
  - 편심성 → "근육이 늘어나면서 힘 쓰기, 천천히 내리기" (예: "3~5초에 걸쳐 천천히 내리세요")
  - 이름에서 뺄 때는 how·cue에 같은 뜻이 이미 있는지 먼저 확인하고, 없으면 쉬운 말로 한 문장 보충한다
- **운동 방식 용어는 아래 표기로 풀어 쓴다.** 괄호는 필드마다 첫 등장에 붙인다. 이름은 표준명만 쓰고 풀이는 how·cue의 첫 등장에 넣는다

  | 분류 | 용어 | 표기 | how·cue 문장 예 |
  |---|---|---|---|
  | 의학 쪽 (쉬운 말(원어)) | 패시브 | 힘 빼고 맡기기(패시브) | 힘을 완전히 빼고 체중에 맡기세요. |
  | | 액티브 | 스스로 힘쓰기(액티브) | 스스로 근육에 힘을 주어 천천히 움직이세요. |
  | | 끝범위 | 움직임의 맨 끝(끝범위) | 편하게 갈 수 있는 맨 끝까지만 가세요. 통증이 생기면 거기서 멈추세요. |
  | | PAILs/RAILs | 끝에서 힘주고 버티기(PAILs/RAILs) | 끝까지 간 자세에서 몸을 제자리에 둔 채 10초 힘을 주고 버티세요. |
  | 운동·기술 쪽 (용어(쉬운 말)) | 릴리즈 | 릴리즈(뭉친 곳 눌러 풀기) | 시원하다고 느낄 정도로만 눌러 풀어 주세요. 아프면 힘을 줄이세요. |
  | | 브레이싱 | 브레이싱(배에 힘줘 몸통 잡기) | 기침하기 직전처럼 배에 힘을 주어 몸통을 단단히 잡으세요. |
  | | 숄더 패킹 | 숄더 패킹(어깨 내려 고정하기) | 어깨를 귀에서 멀리 내리고 날개뼈를 등 아래로 살짝 당겨 고정하세요. |
  | | 모빌리티 | 모빌리티(관절 움직이는 범위) | 관절이 부드럽게 움직이는 범위를 넓히는 운동입니다. |
  | | CARs | CARs(관절 크게 돌리기) | 아프지 않은 범위에서 가장 큰 원을 그리듯 천천히 돌리세요. |

  - 릴리즈는 릴랙스(스스로 힘 빼서 긴장 풀기)와 다르다. 릴리즈는 폼롤러·공으로 **밖에서 눌러** 풀어 주는 것이다
  - 패시브는 "내 힘은 빼고 남이 늘려 줌"이고, 릴리즈는 "눌러서 풂"이다. "패시브 릴리즈"처럼 합쳐진 이름은 이름 정리 때 따로 본다
  - "홀드"·"드릴"은 박스에서 설명 없이 쓰는 말이라 그대로 둔다. 프로트랙션·레트랙션은 위 의학·해부 용어 규칙을 따른다
  - PAILs/RAILs 풀이는 환자용으로 줄인 것이다. 임상 검수(PT)에서 확인한다
- **how·cue 문구를 고치거나 새로 쓸 때는 앱의 말투에 맞춘다.** "~하세요" 체로, 한 문장에 동작 하나와 몸 느낌 하나를 쓴다. **긍정문으로 쓴다** — "~하지 마세요"·"~않게" 대신 해야 할 동작을 말한다 (예: "허리가 꺾이지 않게" → "배에 힘을 주어 허리를 평평하게 유지하세요"). 통증 위험이 있는 동작(끝범위·릴리즈 등)에만 "통증이 생기면 멈추세요"를 붙이고 모든 문장에 반복하지 않는다. 폭력·위협 느낌의 비유("때린다고 생각하고" 등)는 쓰지 않고 일상 비유("기침하기 직전처럼")를 쓴다

### 중복 처리

- 운동명과 기본 동작은 공통이어도, **why(왜 이 원인에 이 운동인가)·큐·주의할 부위는 원인별로 다르게** 쓴다

## 확정된 검사 판정 기준

근거를 확인해 정한 값이다. 바꾸자는 의견이 있으면 근거를 함께 제시한다.

- **토마스 검사**: "늘어뜨린 다리의 허벅지가 침대 면에 닿는가"로 판정한다
- **균형 검사**: 눈 감고 **10초**로 통일한다 (근거: 18~39세 평균 약 13초, 5초 미만은 낙상 위험 신호, 10초 이상 유지는 낮은 사망 위험과 연관)

## 미결 — 판단 요청

- 벽 발목 가동성 운동의 시작 거리가 5cm(스쿼트 무릎 a·허리 b·발목 a 등)이고 검사는 8cm다. 의도된 차이(운동은 더 쉽게 시작)인지, 통일해야 하는지 판단이 필요하다
