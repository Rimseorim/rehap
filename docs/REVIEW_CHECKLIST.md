# 화면 통일성 점검 체크리스트

SCREENS.md 흐름 순서대로 화면을 순회하며 아래 기준으로 점검한다.
발견한 불일치는 화면 ID + 위치 + 내용으로 기록.

---

## 1. 어조 / 문구

- [ ] 존댓말 톤이 화면마다 일관적인가 (질문, 설명, 버튼 모두)
- [ ] 같은 의미에 다른 단어를 쓰고 있지 않은가
      예: "다음" / "확인" / "계속하기" / "진행"
- [ ] 문장 길이·줄바꿈 패턴이 비슷한 화면끼리 유사한가

## 2. 버튼 / UI 패턴

- [ ] 주 액션 버튼 위치가 화면마다 동일한가 (하단 고정 등)
- [ ] 뒤로가기 버튼 표시 방식이 일관적인가
- [ ] 진행 바(ProgressBar)가 모든 화면에서 노출되는가 (DESIGN.md 원칙)
- [ ] ChoiceButton 선택 상태 표시가 일관적인가 (테두리/배경)

## 3. 질문 설계 (CLAUDE.md 핵심 원칙 대조)

- [ ] "원인 먼저, 운동 나중" — 감별 끝나기 전에 운동이 노출되지 않는가
- [ ] "이유를 붙인다" — 운동 처방마다 "왜 이 운동인가" 설명이 빠짐없이 있는가 (ExerciseCard 필수 항목)
- [ ] "단계는 작게" — StageIndicator(맨몸→PVC→빈 바→바벨)가 항상 표시되는가
- [ ] "위험 신호는 즉시 멈춤" — danger 분기에서 재활 루트로 이어지지 않고 병원 안내로 전환되는가
- [ ] 1화면 1질문 원칙 위반(한 화면에 질문 여러 개) 없는가
