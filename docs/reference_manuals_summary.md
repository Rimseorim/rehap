## 1. 호흡 세미나 (FMS Breathing, 53p) — 전체 읽음

- **다차원 모델(p6)**: 생화학적(CO2/pH) · 생체역학적(호흡패턴) · 정신생리학적(스트레스/불안) 3차원. 단일 검사로 판정 불가 → 우리 앱의 "복합 원인 처리(구조적→과부하 순)"와 유사하게 다차원 감별 필요성 시사.
- **호흡 패턴 장애(p8~10)**: 흉식/상부흉곽 우세 호흡, 역설적 호흡(들이쉴 때 배가 안쪽으로) → 목·허리·골반 통증, 요실금과 연관. **우리 앱 "허리" 통증부위 원인 태그에 호흡패턴 이슈 추가 검토 가능**.
- **호흡 스크린(p21~24)**: 호흡정지시간(BHT) 25초 미만 + 4문항 설문 → 민감도 0.89로 호흡기능장애 선별. Red(<25초)/Yellow(26-35초)/Green(>35초) 신호등.
- **적용 원칙(p25)**: "나쁜 호흡 + 좋은 움직임 = 호흡회복 우선", 2~3주 후에도 개선 없으면 병원 의뢰 — **우리 앱 "위험신호 즉시 병원" 원칙과 동일 로직, 재활 루트 내 재평가 주기(2~3주) 설계 참고 가능**.
- **운동 프로그레션(p26~41)**: Crocodile Breathing → Supine/Quadruped/Kneeling FRC → Stacked Spine(회전) → Standing 순으로 난이도 상승. **"단계는 작게" 원칙의 구체적 프로그레션 모델로 참고 가능** (맨몸→PVC→바벨 순서 설계에 참고).

## 2. FMS Level 1 (94p) — 전체 읽음

### 핵심 철학 (앱과 직접 연결)
- **원칙1 "먼저 바르게, 그다음 자주"(p9)**: 질(quality) 확보 후 양(quantity) — 우리 "5분 완주" 설계에서도 정확한 감별이 속도보다 우선되어야 함을 뒷받침.
- **원칙2 "보호→교정→발달"(p9~10)**: 통증/기능제한 있는 패턴에 부하를 얹지 말 것. **우리가 삭제한 "대체 WOD 카드"가 왜 잘못이었는지의 학술적 근거** — 기능제한에 피트니스를 더하면 안 됨.
- **가동성이 안정성보다 항상 우선(p51)**: 알고리즘 순서 = ASLR·숄더모빌리티·발목모빌리티(가동성) → 로터리스태빌리티·트렁크스태빌리티푸쉬업(안정성/운동제어) → 인라인런지·허들스텝·딥스쿼트(기능적 패턴). **우리 "구조적 원인(가동성) → 과부하 우선순위" 원칙과 완전히 일치하는 위계 구조**.

### 동작별 검사·판정 기준 (감별질문 문구 다듬기에 참고)
- **딥스쿼트(p17-20)**: 무릎 외반 붕괴, 대퇴골이 수평선 아래로 안 내려감, 발뒤꿈치 들림 → 우리 "스쿼트-무릎/발목" 감별질문 문구 참고 가능.
- **허들스텝(p21-24)**: 스탠스다리 골반·요추 흔들림, 균형상실 → "런지/스쿼트-고관절" 원인 구분에 참고.
- **인라인런지(p25-30) + 발목클리어링**: 뒷무릎이 내측복사뼈 앞으로 못 나가면 발목 가동성 제한(Red/Yellow/Green 기준) → **"발목" 통증부위 원인 판정 컷오프로 직접 활용 가능**.
- **숄더모빌리티(p31-34) + 어깨클리어링**: 손 길이 대비 양손 거리로 등급화, 별도 충돌 클리어링 테스트 필요(모빌리티만으론 충돌 못 잡음) → **"어깨/흉근" 감별질문에 별도 충돌 확인 질문 추가 검토**.
- **ASLR(p35-38)**: 햄스트링 테스트로 오해받지만 실제론 요추골반 안정화+대측 다리 신전 능력 → **"데드리프트-허리" 원인 태그(가동성 vs 코어안정성) 구분 문구에 참고**.
- **트렁크스태빌리티푸쉬업(p39-42)**: 반사적 시상면 안정성, 척추 흔들림 여부로 판정 → **"수평프레스-허리/코어" 원인 구분**.
- **로터리스태빌리티(p43-46)**: 몸통 좌우 흔들림 저항 능력 → **"로우/키핑-코어" 원인 태그**.

### 운동 처방 로직 (Red/Yellow/Green, p60-64)
- 특정 패턴이 기능제한(1점/0점)이면 그 패턴을 직접 쓰는 운동은 **전면 금지**(빨간불), 간접 사용은 주의(노란불), 미사용은 허용(초록불).
- 실제 운동 200여개에 대한 신호등 매핑 표 있음(p63-64) — 데드리프트/스쿼트/풀업 등 CrossFit 종목별로 "이 원인일 때 어떤 운동을 피해야 하는지" 표로 정리돼있음. **재활 루트의 "제외 운동 목록" 설계에 직접 활용 가능** (원한다면 이 표만 발췌해서 우리 8동작에 매핑해줄 수 있음).

### 모터컨트롤 스크린(부록1, p65-80)
- Y밸런스 테스트 기반, 하체(포워드리치)·상체(수평리치) 좌우 비대칭 측정. 발 길이 2배 미만이면 실패, 좌우 차이 4cm 이상이면 비대칭.
- **"재평가" 단계에서 좌우 비대칭 기반 진급/보류 판정 로직에 참고 가능**.

### FMS 수정 버전(부록2, p81-87)
- 낙상 위험/균형 문제 있는 사람 대상 축약판(4개 테스트만). **고령/초보 크로스피터용 "쉬운 감별 경로" 설계에 참고 가능** — 지금 앱엔 없는 개념.

## 3. FMS Level 2 (95p) — 전체 읽음 (교정운동 매뉴얼)

### 핵심 프레임워크 — 우리 앱에 가장 직접 적용 가능한 부분

**교정 3단계 순서(p59~60)**: `가동성 확보 → 운동제어능력 확보 → 퍼포먼스(기능적 로딩)`. 매 세션 이 순서를 지키되, 가동성이 개선 안 되면 다음 단계로 넘어가지 않음. **우리 3단계 재활 루트(기초재활→재평가→운동복귀) 명칭을 이 프레임에 맞춰 재정의하면 이론적 근거가 더 명확해짐** — 예: 기초재활=가동성, 재평가=운동제어능력, 운동복귀=기능적 로딩.

**국부적 상호의존성/Joint-by-Joint(p40~42)**: 관절이 가동성 관절과 안정성 관절이 교대로 배치됨.
| 안정성 관절 | 가동성 관절 |
|---|---|
| 발 | 발목 |
| 무릎 | 고관절 |
| 요추 | 흉추 |
| 견갑골 | 경추 |
| 팔꿈치 | 어깨 |
| 손 | 손목 |
→ **원인 태그(구조적 가동성 vs 과부하) 분류 로직의 해부학적 근거로 직접 활용 가능**. 예: 무릎 통증인데 원인이 발목(가동성 관절) 제한인 경우 vs 무릎 자체(안정성 관절) 과사용인 경우를 구분하는 논리.

**"기능제한에 피트니스를 더하지 말라" / "부정적 요소를 덜어내라"(p81~82)**: 1점(기능제한) 패턴을 직접 사용하는 운동은 회복될 때까지 전면 배제. **우리가 삭제한 대체 WOD 카드가 왜 위험했는지의 2차 근거**.

**신호등(Red/Yellow/Green) 운동 매핑 표(p83~87)**: ASLR·숄더모빌리티·발목·로터리스태빌리티·트렁크스태빌리티푸쉬업·인라인런지·허들스텝·딥스쿼트 8개 패턴 각각에 대해 일반 크로스핏 종목(스내치·클린·데드리프트·풀업·오버헤드프레스 등 90개+) 을 Red/Yellow/Green으로 매핑한 표 있음. **우리 앱 8동작과 정확히 겹치는 부분 많음 — "이 원인일 때 피해야 할 동작·대체 동작" 감별질문 결과 문구에 직접 활용 가능**. (표가 방대해서 필요하면 8동작별로 발췌해줄 수 있음)

**케이스 스터디 5개(p76~80)**: 실제 점수표 → 약한고리 식별 → 보호 → 교정 → 재검사 흐름 예시. **우리 앱의 "감별질문→원인 배정→재활루트" 흐름을 검증하는 참고 사례로 유용**.

### 패턴별 교정 전략 — 원인별 운동 처방 콘텐츠 소스
7개 패턴(ASLR, 숄더모빌리티, 발목, 로터리스태빌리티, 트렁크스태빌리티푸쉬업, 인라인런지, 허들스텝, 딥스쿼트) 각각에 대해:
- 가동성 전략 운동 목록 (호흡 교정 → 연조직 → 스트레칭)
- 운동제어능력 전략 (자세1~4: 지지된 자세→매달린 자세→쌓인 자세→서있는 자세 순으로 난이도 상승)
- 검사 방법
이 구조가 **우리 앱의 Phase A/B 운동 프레임워크(맨몸→PVC→빈바→바벨)와 개념적으로 유사** — 자세1~4 진행 순서를 우리 단계별 진급 기준 문구에 참고 가능.

**호흡을 모든 교정의 시작점으로(p47~48)**: 모든 패턴 교정운동 서킷의 첫 항목이 항상 "Crocodile Breathing" 등 호흡 교정 — 호흡세미나 내용과 일치. **우리 앱에 호흡 체크 질문이 없다면 추가 검토 여지 있음** (단, v1 범위 초과 가능성 있어 우선순위 낮음).

**용어 사용 원칙(p38)**: 고객에게 "실패", "기능장애" 같은 용어 쓰지 말고 긍정적 언어 사용 — **우리 앱이 이미 잘 지키고 있는 원칙**(태그+진단명만 노출, 내부 분류 코드 숨김)과 일치. 확인차 참고.

**"모든 문제를 다 고치려 하지 말고 알고리즘 순서상 가장 우선순위 하나만"(p51, p58)**: 우리 앱의 "복합 원인 처리: 구조적 원인(가동성)→과부하 순 우선" 원칙과 정확히 같은 논리. FMS는 이걸 스코어시트 순서(검사 효율용)와 알고리즘 순서(교정 우선순위용)를 분리해서 설명 — **우리 앱도 "감별질문 순서"와 "원인 우선순위 로직"이 다를 수 있음을 명확히 구분해서 문서화하면 좋을 듯**.

## 4. SFMA (194p, 임상 감별진단 도구) — p1-105 정독, 이후 계속

### Top-tier 분류 체계 (앱 원인 분류 로직의 임상적 근거)
결과는 항상 4가지 중 하나로 분류됨:
- **FN (Functional Non-painful)**: 정상, 통증 없음 → 문제 아님
- **FP (Functional Painful)**: 동작은 되지만 통증 있음 → **국소부위 생역학 검사 필요** (우리 앱의 "병원 진료 권유" 트리거 후보)
- **DN (Dysfunctional Non-painful)**: 동작 제한, 통증 없음 → **가동성(MD) 또는 안정성/운동조절(SMCD) 세부 감별** 필요
- **DP (Dysfunctional Painful)**: 동작 제한 + 통증 → 우선 치료 대상

**핵심 통찰 — 우리 "구조적 원인 vs 과부하" 태그의 임상적 근거**: SFMA는 DN을 다시 능동/수동 검사로 나눠 판별.
- 능동 제한, 수동 정상 → **SMCD (안정성/운동조절 기능제한)** = 우리 앱의 "과부하/조절력" 계열 원인에 대응
- 능동/수동 둘 다 제한 → **MD (가동성 기능제한)** = 우리 앱의 "구조적(가동성)" 원인에 대응
→ **"구조적 원인(가동성) 먼저, 과부하 나중" 우선순위 원칙이 임상적으로 정확히 이 로직에서 옴**: 가동성 문제(MD)를 먼저 해결하지 않으면 안정성 운동(SMCD 교정)이 무의미하기 때문.

### 복수분절 굴곡 하위검사 전체 알고리즘 (p80-89) — 데드리프트/힙힌지 계열 원인 감별에 직접 활용 가능
검사 순서와 컷오프:
1. **다리펴고앉은자세**(천추각 80도↑, 척추곡선 균등, 발끝닿기) → FN이면 "체중부하 엉덩관절 굴곡 SMCD"
2. **능동SLR**(70도 기준) → 안됨: 코어/골반위치 문제 의심
3. **안정ASLR**(코어 활성화 후 재검사, 70도) → 좋아지면 "코어(골반위치) SMCD", 안 좋아지면 진짜 가동성 문제
4. **수동SLR**(80도 기준) → 안됨: "후방사슬 가동성 기능제한" 또는 "엉덩관절 가동성 기능제한"
5. **누운자세무릎가슴당기기**(120도 기준) → 엉덩관절 자체 가동성 확인
6. **엎드린자세로킹**(척추 굴곡 균등성) → 척추 자체 문제 분리
→ **"허리/고관절" 통증부위 감별질문에 이 5단계 캐스케이드 논리를 자가진단 버전으로 단순화해서 적용 가능** (각도 측정 대신 "무릎 안 굽히고 발끝 닿나/코어에 힘주면 나아지나" 같은 자가체크 질문으로 변환)

### 복수분절 신전 하위검사 전체 알고리즘 (p90-105) — 데드리프트 락아웃/오버헤드프레스 원인 감별에 활용
- **엎드린자세프레스업** → 척추 신전 체중부하 vs 비체중부하 구분 (FN이면 "서있을 때만 안 되는" 자세 안정성 문제)
- **요추잠금 신전/회전**(50도) → 흉추 회전 문제 vs 요추 문제 분리. **"흉추 가동성 문제가 요추 문제보다 항상 우선 치료"** 원칙 명시 (p90) — 우리 앱 "구조적 원인 우선" 원칙의 구체 사례
- **어깨대굴곡**(170도) → 어깨 굴곡 자체 문제 분리
- **하체 신전(FABER/변형토마스)**: 고관절 굴곡-외전-외회전 자세에서 무릎이 주먹 2개 너비 안 들어오면 고관절/SI 문제. 코어 활성화로 좋아지면 "코어 SMCD", 안 바뀌면 진짜 고관절 가동성 문제 — **안정FABER 검사 로직은 "런지/스쿼트-고관절" 원인 태그 감별질문에 직접 적용 가능**

### 상지패턴 하위검사 (p71-79) — 풀업/프레스/로우 원인 감별
- 어깨 90/90 외회전(90도, 총 아크 150도), 어깨 굴곡/외전(170도), 팔꿈치 굴곡 — 능동/수동 비교로 가동성 vs 안정성 구분
- **어깨 총 가동범위(내회전+외회전=150도) 개념** — 개별 각도가 부족해도 총합이 정상이면 "정상 가동범위로 간주" (보상 패턴 허용 기준) → **감별질문 설계 시 "완벽한 각도"보다 "기능적 총량" 기준이 더 현실적인 자가진단 질문이 될 수 있음**

### 회전 하위검사 (p110-127) — 고관절/경골 내외회전
척추 회전(앉은자세회전, 50도) → 흉부/요추 분리 → 하지 외회전(고관절 40도, 경골 20도) → 하지 내회전 순으로 캐스케이드. 코어 안정화 후 재검사해서 좋아지면 "코어 SMCD", 안 바뀌면 "진짜 가동성 문제" — 앞선 굴곡/신전 검사와 동일한 "안정화 재검사" 패턴 반복. **로우/키핑 등 회전 개입 동작 원인 감별에 참고**.

### 한발서기 하위검사 (p132-147) — 발목/균형 계열
순서: **전정계(CTSIB, 균형감각) → 척추/고관절/코어 안정성(반무릎좁은지지면 검사) → 발목 가동성(배측/저측굴곡, 내반/외반) → 고유수용성감각**(다른 원인 다 배제된 후 최후 진단). **"발목" 통증부위 원인을 균형감각 문제/코어 안정성 문제/발목 자체 가동성 문제로 3분류하는 감별질문 설계에 직접 활용 가능** — 지금 앱이 발목을 가동성 하나로만 보고 있다면 이 3분류가 보강 포인트.

### 팔내리고딥스쿼트 하위검사 (p148-161) — 스쿼트 원인 감별 핵심 레퍼런스
검사 순서 자체가 우선순위: **① 발목 가동성(배측굴곡, 내반/외반) → ② 고관절+무릎 굴곡 → ③ 고관절 회전(내/외회전, 굴곡 자세에서 재평가)**. FMS 딥스쿼트보다 세분화된 버전. **"스쿼트" 감별질문의 하위 원인 태그(발목형/고관절형/무릎형)를 정확히 이 3단계 순서로 재구성 가능** — 우리 앱이 이미 무릎·발목을 스쿼트 제외 대상으로 다루고 있다면(WOD_EXCLUDED에서 확인됨) 이 순서가 원인 우선순위의 임상적 근거가 됨.

### SFMA 최종 조언 + 치료 가이드라인 (p162-179) — 우리 앱 원칙의 직접적 임상 근거
- **7대 임상 규칙(p162)**: "확실하지 않으면 기능제한으로 간주", "가동성 문제에 안정성 운동 금지(가동성이 항상 우선)", "DP→DN→FP 순으로 치료", **"흉추 가동성이 어깨/요추 가동성보다 항상 우선"**(관절-by-관절 이론의 실전 규칙), "통증 원인 불명확하면 근골격계 아닌 다른 진단 고려"(→ 병원 의뢰 트리거).
- **기능의 연속성 4단계**: 무의식적 기능제한 → 의식적 기능제한(우리 앱이 감별질문으로 하는 일) → 의식적 기능 → 무의식적 기능(자동화). **재활 루트 3단계 네이밍에 이 프레임 적용 가능**.
- **3R 치료모델**: 리셋(수기, 우리 앱 범위 밖) → **리인포스(스트레칭/자세교정/생활습관 — "왜 이 운동인가" 설명 콘텐츠에 활용 가능)** → **리로드(운동학습/운동조절 훈련 — 우리 앱 재활 루트 운동 자체)**.
- **4x4 매트릭스 진행 순서**: 자세(누운→매달림→쌓임→선자세) × 저항수준(피드백→자가체중→저항). 표준 순서: 1-1→1-2→2-1→2-2→3-1→3-2→4-1→4-2→1-3→1-4→2-3→2-4→3-3→3-4→4-3→4-4. **우리 앱 "맨몸→PVC→빈바→바벨" 단계화의 이론적 뼈대와 정확히 일치 — 자세 난이도와 저항 난이도를 별도 축으로 분리해서 조합하는 방식은 우리 진급 기준을 더 정교하게 다듬는 데 참고 가능**.
- **롤링 검사**: SMCD가 국소적인지 전신적인지 구별하는 기초 레벨 검사 — 우리 앱 범위 밖(너무 기초적/임상적)이라 낮은 우선순위.

## 5. SFMA2 (172p, Level 2 — 국소부위 정형학적 특수검사 + 교정운동 라이브러리)

### 국소부위 특수검사 (p11-32) — 우리 앱 "병원 진료 권유" 감별질문의 가장 직접적인 근거
경추/고관절/무릎/발목/어깨 각각에 대해 "구조적 손상 의심 상태 → 특수검사명 → 양성 기준 → 확진/배제 목적"이 표로 정리되어 있음. **이게 우리 앱이 "위험 신호"를 판단하는 기준을 훨씬 구체화할 수 있는 자료**임 (지금 앱은 아마도 통증 강도·양상 정도로만 판단 중일 것 — 아래 항목들은 자가진단 버전 질문으로 변환 가능):

| 부위 | 의심 상태 | 자가진단 힌트로 변환 가능한 양성 기준 |
|---|---|---|
| 경추 | 경추 신경근병증 | 팔 아래로 뻗치는 저림/통증, 목 돌릴 때 60도 못 돌아감 |
| 경추 | 상부경추 불안정성 | (전문 검사 필요 — 자가진단 부적합, "즉시 병원" 트리거로만 활용) |
| 고관절 | 관절와순 파열/대퇴비구충돌 | 고관절 굴곡+내회전 시 통증/클릭음, 사타구니 통증 |
| 고관절 | SI관절 기능제한 | 여러 압박 검사 중 3개 이상에서 통증 재현 |
| 무릎 | 십자인대/반월판 손상 | 무릎 내측 통증+클릭음(반월판), 헐거운 느낌(인대) |
| 발목 | 하이 안클스프레인(경비인대) | 발목 조이면 통증, 외회전 스트레스에 통증 |
| 발목 | DVT(심부정맥혈전증) | **종아리 둘레 좌우 차이 남12mm/여15mm 이상 — 명백한 응급 병원 트리거 후보** |
| 어깨 | 충돌증후군 | Neer/Hawkins 계열 3검사 중 2개 이상 양성 (60-120도 구간 통증 등) |
| 어깨 | 회전근개 파열 | 저항 시 급격히 팔이 떨어짐, 외회전 유지 못함 |
| 어깨 | 관절와순 파열(SLAP 등) | 특정 자세에서 증상 재현+통증 |

→ **"팔이 갑자기 뚝 떨어진다", "종아리가 한쪽만 심하게 붓는다", "저림이 팔을 타고 내려간다" 같은 문항을 병원 진료 감별질문에 추가하면 SFMA2의 임상적 근거를 그대로 우리 언어로 옮기는 것**. 특히 DVT 종아리 둘레 차이는 크로스핏 러너/스쿼트 유저에게 실제로 위험한 놓치기 쉬운 신호라 우선순위 있음.

### 교정운동 중재 라이브러리 (p70-141) — 목차만 확인, 상세 미독
경추/상지패턴/복수분절굴곡/신전/회전/한발서기/팔내리고딥스쿼트 패턴별 교정운동이 정리돼 있음(약 70페이지 분량). FMS Level 2에서 이미 유사한 신호등 매핑 표와 패턴별 교정 전략을 확보했기 때문에 **중복도가 높다고 판단, 이번엔 상세 정독 생략** — 필요시 특정 패턴(예: "회전" 챕터, p114-126)만 나중에 요청하면 발췌 가능.

## 6. FCS (123p, Fundamental Capacity Screen) — 전체 읽음

**정체**: FMS/SFMA와 달리 이건 재활/진단 도구가 아니라 **퍼포먼스 복귀 준비도 측정 도구** — "기본 신체 자원(운동조절·자세조절·폭발력·충격제어)이 스포츠 특이적 기술을 쌓기에 충분한가"를 스크리닝. 통증/기능장애 배제가 끝난 사람 대상.

### 우리 앱 "운동복귀" 단계에 참고할 개념
- **4분면 모델**: 운동조절(Movement Control) → 자세조절(Postural Control, 캐리) → 폭발력(Explosive, 점프) → 충격제어(Impact, 바운드/연속점프). **한 영역 실패가 다른 영역 실패를 의미하지 않음** — 우리 앱도 "운동복귀" 판정 시 이런 다차원 체크 없이 단일 재평가로 넘어가고 있다면, 이 다분면 사고를 참고해 재평가 문항을 다양화할 여지 있음.
- **캐리(Carry) 철학(p38)**: "안정화 근육의 지구력이 주동근육의 지구력보다 항상 커야 한다" — 주동근이 먼저 지치는 게 정상이고 안정근이 먼저 지치면 위험 신호. **바벨/케틀벨 캐리형 동작(파머스캐리 등)이 우리 8동작엔 없지만, "왜 코어/자세 안정성이 근력보다 먼저 훈련돼야 하는가"의 설명 논리로 원용 가능**.
- **안전 스크리닝 순서(p13)**: 병력 → FMS(기능평가, 통증 있으면 SFMA로 전환) → 발목/상체 클리어링 → 폭발력 → 충격 → 캐리 순으로 강도를 높여가며 각 단계에서 "통증 Y/N" 분기. **우리 앱의 "위험신호 즉시 중단" 로직과 동일한 계단식 안전장치 구조** — 참고할 만한 안전 문구 설계.
- **케이스 스터디 5개(p92-106)**: 실제 수치(비대칭률, 에너지저장비율 등)로 "약한 고리 하나만 찾아서 그것만 교정" 예시. 좌우 비대칭 5% 이상이면 문제로 판정하는 식의 명확한 컷오프 제공 — **우리 앱 재평가 단계에 "좌우 비교" 질문이 없다면 추가를 검토할 근거 자료**.

### 우리 앱에 낮은 우선순위인 이유
전체적으로 도수 측정 장비(FMS 키트, 악력계, 정밀 줄자)와 수치 기반 컷오프(cm, kg, 초)에 의존 — 자가진단 앱 UX로 옮기기 어려움. 8동작 감별질문보다는 "이미 감별과 재활이 끝난 사람의 스포츠 복귀 준비도"를 재는 도구라 **v1 범위보다는 향후 "운동복귀 완료 판정" 기능을 만들 때 참고 자료로 보관**.

## 7. YBT (32p, Y-Balance Test) — 전체 읽음

**검사 구성**: 하지(전방/후내측/후외측 3방향 리치)와 상지(내측/하외측/상외측 3방향 리치) 버전. 다리/팔 길이로 정규화한 % 거리 + 좌우 비대칭(cm)으로 판정.

### 우리 앱에 활용 가능한 핵심 수치
- **좌우 비대칭 4cm 이상 = 부상 위험 유의 증가**(하지 전방 리치 기준, 반복 검증된 문헌 컷오프). **재평가 단계에서 "좌우 어느 쪽이 더 불편한가/더 안 뻗어지는가" 같은 체감 기반 질문으로 변환해 활용 가능** — 정밀 측정 없이도 "왼쪽이 오른쪽보다 확실히 뻣뻣하다" 같은 자각 증상 질문으로 근사 가능.
- **복합점수(Composite Score) 낮음(하지 기준 약 89.6% 미만) = 부상 위험 증가**하는 문헌 근거 있음. 단일 방향보다 종합 점수가 예측력 높음.
- **전방 리치는 발목 배측굴곡·고관절 가동성과 상관**, **후내측/후외측 리치는 고관절+코어 안정성과 상관** — FMS/SFMA의 "가동성 vs 안정성" 이분법과 정확히 같은 논리가 여기서도 재확인됨.
- **상지 버전은 어깨/코어 안정성 테스트로, 편측 운동(런지·풀업 등) 복귀 준비도 판단에 참고 가능**.

### 우리 앱 활용 방향
정밀 측정 도구라 그대로 이식은 안 되지만, **"재활 루트 재평가" 단계에서 좌우 비교 자각 질문("아픈 쪽 다리로 설 때 균형 잡기가 확실히 더 힘든가?" 등)을 넣으면 YBT의 핵심 원리(비대칭=위험신호)를 자가진단 버전으로 구현 가능**. 특히 "고관절/무릎/발목" 통증부위의 재평가 단계에 적합.

# 종합 결론 — 우선순위별 다음 액션

**즉시 적용 가능(감별질문 문구 수준 수정)**
1. "발목" 원인을 가동성 하나로만 보고 있다면 SFMA 한발서기 로직처럼 **균형감각/코어안정성/발목가동성 3분류**로 세분화
2. "스쿼트" 원인 태그를 SFMA 팔내리고딥스쿼트 순서(**발목→고관절+무릎굴곡→고관절회전**)로 재정렬
3. 병원 진료 감별질문에 SFMA2 특수검사 기반 문항 추가: **"팔이 갑자기 뚝 떨어진다"(회전근개), "종아리 한쪽만 심하게 붓는다"(DVT), "저림이 팔/다리를 타고 내려간다"(신경근병증)**

**구조/설계 참고(우선순위 논리 재정비)**
4. "구조적 원인(가동성) 먼저, 과부하 나중" 원칙의 임상적 근거(FMS/SFMA의 관절-by-관절 이론, 흉추 우선 규칙)를 내부 문서에 명시해두면 향후 원인 분류 판단 시 일관성 유지 용이
5. 재활 루트 3단계 진급 기준을 SFMA 4x4 매트릭스(자세×저항 두 축)처럼 좀 더 세분화된 진급 로직으로 검토

**낮은 우선순위 (v1 범위 밖으로 보류 권장)**
6. FCS 기반 "운동복귀 완료 판정"(비대칭·폭발력 측정) — 정밀 측정 필요해 지금 UX와 안 맞음, 추후 검토
7. SFMA2 교정운동 라이브러리(p70-141) 상세 발췌 — FMS L2와 중복도 높아 보류, 특정 패턴 필요시 요청

원본 자료: FMS L1/L2 이미지 렌더링 완독, SFMA1 이미지+텍스트 혼합 완독(p1-180)+참고문헌 생략(p181-194), SFMA2 특수검사 완독+교정운동 목차만 확인(중재 상세 미독), FCS/YBT/호흡세미나 전체 완독.
