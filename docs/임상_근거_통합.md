# 임상 근거 통합 — 앱 원칙의 근거 매핑

> 출처: `docs/reference_manuals_summary.md` (FMS/SFMA/SFMA2/FCS/YBT 요약) 재구성. 새 조사 없음.

## 1. 왜 이 문서인가

CrossFit Rehab Guide의 핵심 원칙(원인 먼저·구조적 원인 우선·단계는 작게 등)은 임의로 정한 게 아니라 FMS/SFMA 계열 임상 프레임워크에서 가져왔다. 근거가 여러 요약 문서에 흩어져 있어, 원칙 하나당 어느 임상 규칙에서 왔는지 한 곳에서 확인할 수 있게 정리한다.

## 2. 구조적 원인 우선순위 원칙

**앱 원칙** (CLAUDE.md 핵심 원칙 3): 복합 원인 처리 시 구조적 원인(가동성) → 과부하 순으로 우선한다.

**임상 근거**:
- SFMA "복수분절 신전 하위검사"(p90-105) — 요추잠금 신전/회전 검사에서 "흉추 가동성 문제가 요추 문제보다 항상 우선 치료"라고 명시 (p90)
- SFMA "7대 임상 규칙"(p162) — 관절-by-관절(Joint-by-Joint) 이론의 실전 규칙으로 "흉추 가동성이 어깨/요추 가동성보다 항상 우선"을 재확인
- 관절-by-관절 이론: 관절마다 가동성 우선 관절과 안정성 우선 관절이 교대로 쌓인다는 전제 — 흉추(가동성 우선)가 막히면 인접 관절(요추·어깨)이 보상하며 과부하로 이어진다는 기전

**적용**: 앱의 "가동성부족" 태그가 "과부하/컨디셔닝부족" 태그보다 원인 후보 우선순위에서 앞서야 하는 이유가 여기서 나옴.

## 3. SFMA 7대 임상 규칙 → 앱 매핑

| SFMA 규칙 (p162) | 앱에서의 대응 |
|---|---|
| 확실하지 않으면 기능제한으로 간주 | 감별질문에서 애매한 응답 처리 시 "정상"보다 "기능제한" 쪽으로 분류하는 기본값 |
| 가동성 문제에 안정성 운동 금지 (가동성이 항상 우선) | 재활 루트 배정 시 가동성 원인이 있으면 안정화/근력 운동보다 가동성 운동을 먼저 배정 |
| DP(기능장애+통증) → DN(기능장애+무통) → FP(기능+통증) 순 치료 | 재활 루트 단계 순서(기초재활→재평가→운동복귀)의 우선순위 뼈대 |
| 흉추 가동성이 어깨/요추 가동성보다 항상 우선 | §2 구조적 원인 우선순위 원칙 |
| 통증 원인 불명확하면 근골격계 아닌 다른 진단 고려 | danger 카드(병원 안내) 트리거 조건 |
| (나머지 2개는 참고 요약에 미기재 — 필요시 SFMA 원문 p162 재확인) | — |

## 4. 기능의 연속성 4단계 → 재활 루트 3단계 네이밍

**SFMA 개념** (p162-179):
1. 무의식적 기능제한 (본인도 모르는 문제)
2. 의식적 기능제한 (감별질문으로 드러나는 문제 — 우리 앱이 여기서 하는 일)
3. 의식적 기능 (의도적으로 올바르게 수행)
4. 무의식적 기능 (자동화된 정상 패턴)

**앱 재활 루트 3단계**: 기초재활 → 재평가 → 운동복귀

- 감별질문 자체가 2단계("의식적 기능제한" 발견)에 해당
- 기초재활~재평가는 2→3단계(의식적으로 올바른 패턴 만들기) 과정
- 운동복귀는 3→4단계(자동화) 진입을 확인하는 단계로 대응

## 5. 참고용 (v1 범위 밖, 향후 확장 시)

- **3R 치료모델**: 리셋(수기, 범위 밖) → 리인포스(스트레칭/자세교정/생활습관 — "왜 이 운동인가" 설명 콘텐츠에 활용 가능) → 리로드(운동학습/운동조절 훈련 — 재활 루트 운동 자체)
- **4x4 매트릭스**(자세×저항수준): 자세 난이도(누운→매달림→쌓임→선자세)와 저항 난이도(피드백→자가체중→저항)를 별도 축으로 분리하는 방식. "맨몸→PVC→빈바→바벨" 단계화의 이론적 뼈대와 일치 — 향후 진급 기준을 더 정교화할 때 참고
